# 中文语音输出与缓存

协调器复用现有Kokoro模型和USB扬声器角色，包含固定任务短句、聊天动态TTS、巡检发现缓存三种用途。模型启动加载和实际声卡播放分别检查；最近状态见[巡检验证](../../doc/AI巡检验证记录.md)。

| 用途 | 生成/触发 |
| --- | --- |
| 固定任务短句 | announcements按对应任务事件排队；支持log、模拟前缀及已配置缓存。独立FAM1回放不等于生产任务完成 |
| 聊天机器人 | 原版Qwen3.5 0.8B回复经现有Kokoro实时合成，进入同一可取消播放队列 |
| 巡检发现 | 目标三个有效定位样本确认后一次“发现xx”；四类WAV预合成缓存于运行根inspection_speech/，现场直接播放 |

固定任务缓存目录与清单由config.json的announcements配置决定，不硬编码日期化资产目录或声卡编号。仓库保留早期36/48句资产生成工具；当前模型和文件身份见[资产说明](../MODELS.md)。

## 播放与录音

播放异步执行，不阻塞巡检控制。任务替换、暂停、手动、录音、退出和取消可清理本任务待播/播放；新会话不补播旧事件。播报队列和超时按现有模块设置执行，失败记录原因，不冒充现场已听到。

USB声卡按VID/PID/角色重新解析，不固定插座或默认HDMI。录音与播放通过现有半双工机制互斥；这不是AEC，不保证播报中随时用语音打断。底盘手动/急停仍独立由FPGA处理。

巡检发现功能、去重、缓存索引和可扩展中文名称只在[巡检指南](../../doc/AI视觉巡检.md)维护；独立目标识别、预览和基础任务不触发巡检播报。

## 固定资产工具

```powershell
powershell.exe -NoProfile -File host/ai_coordinator/build_speech.ps1 -Python '<已有Python>' -OutputDirectory '<新的缓存目录>'
python host/ai_coordinator/speech_assets.py check --assets '<缓存目录>'
python host/ai_coordinator/build_neural_speech.py cache --model-dir '<已有Kokoro目录>' --out '<新的缓存目录>' --sid 3
```

Windows系统语音生成器与Kokoro生成器分别保留，使用各自manifest中的采样率、文案和SHA；不把电脑合成耗时或ASR粗查当成RK播音延迟/发音验收。生成器不负责安装、下载模型或替换系统语音库。

## 当前验收范围

聊天回复及人声曾由用户确认清晰；开机就绪音曾确认。巡检“发现xx”四句缓存已生成并验证复用，但扬声器触发播报尚未实测。原固定短句回放成绩不替代这项现场验收。

巡检播报以实际播放完成回执为准，排队不算已播。取消或失败的目标可在SWA确认恢复时重新通知；不因手动档切回光标档自动补播。
