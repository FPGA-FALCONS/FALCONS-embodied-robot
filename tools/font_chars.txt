# UI 字表：界面用到的全部文案（UTF-8，无 BOM）
#
# 格式：<常量名>:<文案>
#   * `#` 开头为注释、空行忽略
#   * 常量名会变成 `rtl\common\ui_text_index.vh` 里的 localparam：
#       UI_TXT_<常量名>_ADDR / UI_TXT_<常量名>_LEN
#   * 脚本自动收集所有文案里出现的字符（去重，含 ASCII 可打印字符）生成 16x16 点阵字库
#   * 改文案后重跑：python tools\gen_font_rom.py
#
# 依据：doc\使用FPGA实现的差速小车功能设计_ai优化版.md §5（屏幕 UI 与交互）、§6（模块接口）
