#   * 改文案后重跑：python tools\gen_font_rom.py

# ★ 2026-10-18 新增（需求方要求在数据页给两处加带单位的标签）：
#   ① 车头偏航角数字【上方】「航向角/°」
#   ② 车图【下方居中】「车轮转速/rpm」
#   ★ 注意这里引入了 **U+00B0 '°'**（度数符号）—— 此前字符集只有 ASCII 可打印
#     (0x20..0x7E) + CJK，没有它。
#     `build_charset` 的排序键是 (ord > 0x7E, ord)，U+00B0(176) 落在"CJK 组"最前，
#     因此 **所有 CJK 字符的索引整体 +1**（ASCII 段 0..94 不受影响，
#     所以 num_text.v 里的 CH_SPACE=0 / CH_MINUS=13 / CH_ZERO=16 仍成立）。
#     字库与文本 ROM 必须重跑本脚本重新生成，不能混用旧生成物。
LBL_YAW_UNIT:航向角/°
LBL_WHEEL_RPM:车轮转速/rpm
# ★ 2026-10-18（第二批）：上面两条标签改为「中文 24px 格 + 符号 16px 格」混排，
#   所以把单位后缀单独拆成两条文案，由 sm 通路（16px）渲染：
#     航向角（LBL_YAW，已有） + /°（LBL_DEG）
#     车轮转速（新增 LBL_WHEEL_TXT） + /rpm（LBL_RPM）
#   ★ 为什么要拆：lg 通路一个字符固定占 24px 格，ASCII 字符笔画只有 7~12px，
#     居中后左右各留 6~7px 空白，看起来"散"（实测 '/' 空隙 24-10=14px）。
#     sm 通路是 16px 格，'/'、'p'、'm' 的空隙降到 6/6/4px，与数字的 '0'(空隙 6px) 一致。
LBL_DEG:/°
LBL_RPM:/rpm

#   显示在数据页「航向角」标签正上方，**红色**。

#     上板时很难判断是"没转"还是"IMU 没起来"，所以直接把失败状态画在屏上。
