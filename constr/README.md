# constr\ —— 板级约束（管脚 .cst / 时序 .sdc）

## 两条硬规则

1. **`.cst` 与 `.sdc` 必须成对给出。**
   只给 `.cst` 不给 `.sdc` 时，工具按默认 100 MHz 估算时钟，会报出假的时序违规
   （曾出现 `slack −7.32 ns` 的假违规，真实约束是 50 MHz / 20 ns）。
2. **引脚逐针抄自硬件手册，不靠推测。**
   权威依据是 `doc\ACG720_引脚接线手册_RevI.pdf`（J1~J9 外设接口）。
   曾出现"整排错位"的事故：旧约束记录的是飞线接法，改用主板 J4/J5 排线直连后
   21 根电机信号**全部**对不上 —— 但两版各自自洽，综合与上板都"能过"。

> ⚠ 不要照抄 vendor 包里 `examples\*\*.cst` 或 `constraints\*.cst` 当权威：
> 那些是**示例**，板级约束由各工程按手册自己逐针写。

## 命名与对应关系

| 文件 | 对应 |
| --- | --- |
| `falcons.cst` / `falcons.sdc` | `build.tcl`（主工程，顶层 `falcons_top`） |

后续分阶段工程（如先只上板复验速度闭环）各自一对 `.cst/.sdc`，
在对应的 `build_<阶段>.tcl` 里给出，避免互相覆盖。

## 硬件基线（抄约束前先确认）

| 项 | 值 |
| --- | --- |
| 板卡 | 高云 GW5AT-138B（ACG720 开发板） |
| 系统时钟 | 50 MHz，管脚 **Y18** |
| 串口 | 板载 USB 转串口，TX=**M15**，115200 8N1；闭环调参用 RX=**J21** |
| 板载按键 | S0=**F15**（复位）、S1=**A20**、S2=**B20**、S3=**A21**、S4=**B21** |
| IMU | **J2** 接口：SCL→**A14**、SDA→**A13**、SA0/SDO→**A16**、CS→**A15** |
| 电机/编码器 | 主板 **J4/J5** 排线直连 WHEELTEC D24A（21 根信号，逐针复验结论见 `doc\工作记录.md` §14.2 —— `doc\电机硬件标定记录.md` **尚未建立**） |

## 待复核项（写在文件头，别丢）

- ★ **雷达 RX 必须接 C14（J3.3），不要接 A15**：手册 J2.6 = IMU `CS`，而模块库雷达例程
  `acg720_m10_hdmi.cst` 把 A15 当雷达 RX —— J1 与 J2 同网络，同挂一条网络会**对打**，
  可能损坏 IO，或表现为 IMU / 雷达随机失效（依据：`doc\使用FPGA实现的差速小车功能设计_ai优化版.md` §10-2）。
  改法只需动一行 `IO_LOC`，端口名 `i_radar_rx` 与 RTL 不变；**飞线到 A15 的接法仅适用于不装 IMU 的场合**。
- 现有 `car_fpga` 的两个 `.cst` 抄自手册 **RevI/027**；雷达文档已按 **028**（雷达 TX `A15` → `C14`）。
  ✅ **2026-10-15 已用 `tools\check_pin_constraints.py` 对 RevI/027 逐针复验通过**（J2/J4/J5/J6/J7 五张表、
  35 根信号全部一致，60 个引脚无重复，12 条 `J1.xx` 注释 0 条不符）。
  若 028 还改过 J2/J4/J5/J6/J7，就要用同一个脚本（已从 `car_fpga` 迁入本工程，见 `tools\README.md`）
  对**新版手册**再跑一遍。
- 手册自带解析坑：封面与页眉都印着 "J4 电机驱动 A/B"，宽松锚会在封面误触发、页眉提前 break。
  锚必须取跨页唯一特征（如 J4/J5 标题行末的 `Pin1悬空，保留原位置`）。

## HT10A接收机映射（2026-10-16）

J6.1..6 分别接接收机 CH4/CH2/CH5/CH7/CH6/CH8，先经电平转换；**顶层 `i_rc_pwm[i]` ↔ J6.(i+1)**。
**bit5（J6.6 / CH8）闲置**，已由 `SIG_VALID_MASK = 6'b011111` 排除出"信号有效"判定（该路悬空不影响开车）；
**bit3（J6.4 / CH7）是 select** —— 在用、参与判定，别把它当预留位。
详细表见 `doc/HT10A接线与验收.md` §2（**接线唯一真源**）。IO_LOC/IO_PORT 未改，不能将 J6 丝印 CHn 直接等同于接收机 CHn。
