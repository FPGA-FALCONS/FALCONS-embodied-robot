# 导航：操作与控制架构

核对：2026-11-09。本文合并基础避障操作、导航控制及生产接入说明；参数与单位见[参数总表](参数总表与待定清单.md)，AI多点队列见[巡检指南](AI视觉巡检.md)。基础导航仍由FPGA独立完成。

## 按键

| 操作 | 用途 |
| --- | --- |
| 切到光标档 | 操作屏幕，不用摇杆驾驶 |
| 摇杆 | 编辑时移动选点准心；浏览时选择左侧页面 |
| CH8 上 / 下 | 编辑时切换右侧辅助选项 |
| CH5 下拨（确认） | 执行选中项；运行时暂停；暂停时继续；故障时重试 |
| CH5 上拨（返回） | 运行时暂停；暂停/故障时取消；完成后进入编辑；编辑时退出 |

## 开始一次导航

1. 切到光标档，在左侧选择“避障导航”并确认。
2. 等地图显示后，移动准心到目的地，选择“确认路径点”并确认。
3. 可继续添加目的地，最多 16 个，小车按添加顺序执行。可选择“撤销路径点”或“清除所有路径点”。
4. 选择“开始导航”并确认。运行期间不能修改目的地。

## 暂停、手动和恢复

- 运行时按确认或返回，进入暂停。
- 切到手动档也会暂停任务；接管准备完成、摇杆回中后可手动驾驶。
- 手动移动后，先停车、切回光标档，再确认“继续导航”。小车从当前位置重新规划到当前未完成的目的地。
- 切回光标档不会自动恢复。手动经过目的地不会将它标记为完成。
- 停机条件尚未解除时不能继续。

## 完成、无路和故障

| 显示状态 | 可以怎么操作 |
| --- | --- |
| 已到达 | 只查看结果，不能选点。按返回进入编辑，再选下一次任务 |
| 无路 | 保留目的地并等待新路线；可按返回暂停，再返回取消 |
| 导航暂停 | 确认继续；返回取消任务并退出交互 |
| 控制故障 | 排除问题后确认重试当前目的地；返回取消 |

完成后按返回进入编辑，会清除旧任务点，准心回到当前位置，辅助菜单选中“确认路径点”。编辑时再按返回，退出到左侧页面浏览。

取消会清除本次目的地；暂停会保留进度。完成、暂停、取消和手动驾驶均不清地图、不重置定位原点。

## 状态切换

| 当前状态 | 操作或事件 | 下一状态 |
| --- | --- | --- |
| 浏览 | 选择避障导航并确认 | 编辑 |
| 编辑 | 添加目的地后开始 | 运行 |
| 编辑 | 返回 | 浏览 |
| 运行 | 确认 / 返回 / 切手动 / 停机条件 | 暂停 |
| 暂停 | 切回光标档并确认，停机条件已解除 | 运行 |
| 暂停 / 控制故障 | 返回 | 浏览，任务取消 |
| 运行 | 所有目的地完成 | 完成 |
| 完成 | 返回 | 编辑，新任务 |
| 运行 | 控制器报告故障 | 控制故障 |
| 控制故障 | 确认重试 | 运行，仍执行当前目的地 |

无路时仍在等待路线，不会跳过目的地。灰色辅助项不可操作。板载 S3 强制切页会取消任务；S2 是全局清零，应停稳并退出任务后使用。

## 规划窗口整定

参数整定页第15行“规划窗口”默认 128，范围 2～255，步长 1。CH2 上下选行，CH4 左右调整，CH5 下恢复默认；手动档不可修改。新值从下一轮规划生效，复位后恢复 128。它控制内部短段长度，默认每段最多相差 127 格；同向中间点不会要求小车逐点停车，控制器仍接收最远同向目标。

第5行“导航转向”与第16行“AI转向”分别设置普通导航和视觉巡检的行进纠偏限幅，均默认约30°/s，互不覆盖。原地对准速度仍按原控制器固定限幅执行。

## 三个任务入口，共用底盘

| 入口 | 调度与执行 |
| --- | --- |
| 非避障导航页 | nav_free_ctrl管理点表与间断/连续模式，nav_ctrl直接跟踪用户点 |
| 避障导航页 | nav_obstacle_ui管理目的地点表，现有Dijkstra规划及nav_drive产生当前控制目标，nav_point_ctrl执行 |
| AI视觉巡检 | RK管理多点队列、视觉障碍和返航，每次提交单个目标，复用同一FPGA导航与nav_point_ctrl |

原两个导航页和RK巡检各自维护任务，不互相覆盖点表。聊天、显示和独立识别没有导航权限。手动、急停、遥控失效、堵转及控制所有权在顶层仲裁，不能由RK绕过。

## 坐标、量纲和符号

导航位置是固定参考系signed毫米，初始车头+x、左+y；yaw逆时针为正，单位0.01°。内部前/左投影为：

```text
dx = target_x - car_x
dy = target_y - car_y
ahead = dx*cos(yaw) + dy*sin(yaw)
left  = -dx*sin(yaw) + dy*cos(yaw)
psi = atan2(left, ahead)
```

CORDIC计算目标方位，角差按跨±180°的最短差处理。底盘center/diff单位是编码器窗口计数；`left_target=center-diff`、`right_target=center+diff`，因此正diff对应左转。航向反馈与命令必须维持这一符号链，显示取整值不代替控制角速度。

物理mm/s与窗口计数换算使用现有定点流水和里程系数；运行参数由tune_ctrl提供，派生减速系数用迭代除法器在参数改变时计算，不在控制组合路径放通用除法。

## 原非避障控制

`rtl/nav/nav_ctrl.v`保留间断寻点和非间断寻点：对准后跟踪、接近目标减速、停车/切点、最终整趟完成。连续切点的几何条件由NP_CUT_DIST_MM、NP_CUT_DEG、NP_MIN_SPACE_MM及代码中的角差/点距判断决定，不等同巡检每点自动续发。

原点表/预取点接口以nav_ctrl和nav_free_ctrl的当前端口为准。`o_done`表示整趟完成，不在中间点发整趟结束信号；软件不能把它当成巡检每个路径点的到达回执。

## 避障单点执行器

`rtl/nav/nav_point_ctrl.v`接受`i_cmd_valid`、目标毫米坐标、10ms节拍、同组位姿/速度、堵转状态及运行参数，输出`o_center/o_diff/o_auto_valid/o_done/o_linear_active/o_fault`。

正常握手为请求升高 → 本次到点停车完成升高 → 撤销请求 → 完成清零。新任务不能继承旧done；急停撤销旧目标并重新完成停车握手。ALIGN/TRACK负责对准与跟踪，STOP/DONE/FAULT/ESTOP分别处理停车、完成与异常，计算阶段分拍，停车抢占不等待下一个10ms节拍。

到点半径25mm、停稳线速度50mm/s、角速度3°/s并保持10个控制周期；非避障单点超时30s，避障执行器300s。它们是代码参数，不是已保证的实际定位精度。巡检0.3秒等待只是在原STOP回执之后的RK观察流程，不增加FPGA停稳证明。

## AI控制权与图层

`rtl/ai/inspection_nav_control.v`在明确物理确认、当前session/task/epoch/command及已提交图层下授权。进入巡检先取得零输出，再释放旧停车握手、等待执行器空闲后提交目标。同一授权任务的后续路径点不需要逐点人工确认；手动或人工暂停撤销旧授权，恢复需明确确认。

视觉raw/cost与雷达地图在共享读取处合成。新层停车后完整提交，原子换bank并使旧规划失效；规划、路线复核和前探读同一有效地图。RK负责H投影和膨胀，不在FPGA加第二套视觉几何/规划器。

巡检只按真实当前命令回执推进点序，最后一点完成后在最新地图返回任务开始时实际起点。无路保持目标，不跳点。具体交互与记录见[巡检指南](AI视觉巡检.md)。

## 地图和前探

地图、规划膨胀、前探与控制到点半径是不同量；基础地图尺寸、显示比例和前探参数见[参数总表](参数总表与待定清单.md)。视觉障碍独立提交，不永久写入雷达存储。
