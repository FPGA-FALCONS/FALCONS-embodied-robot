# 避障导航操作指南

## 按键

| 操作 | 用途 |
| --- | --- |
| 切到光标档 | 操作屏幕，不用摇杆驾驶 |
| 摇杆 | 编辑时移动选点准心；浏览时选择左侧页面 |
| CH8 上 / 下 | 编辑时切换右侧辅助选项 |
| CH5 下拨（确认） | 执行选中项；运行时暂停；暂停时继续；故障时重试 |
| CH5 上拨（返回） | 运行时暂停；暂停/故障时取消；完成后进入编辑；编辑时退出 |

## 开始一次导航

1. 切到光标档，在左侧选择“避障导航”并确认。
2. 等地图显示后，移动准心到目的地，选择“确认路径点”并确认。
3. 可继续添加目的地，最多 16 个，小车按添加顺序执行。可选择“撤销路径点”或“清除所有路径点”。
4. 选择“开始导航”并确认。运行期间不能修改目的地。

## 暂停、手动和恢复

- 运行时按确认或返回，进入暂停。
- 切到手动档也会暂停任务；接管准备完成、摇杆回中后可手动驾驶。
- 手动移动后，先停车、切回光标档，再确认“继续导航”。小车从当前位置重新规划到当前未完成的目的地。
- 切回光标档不会自动恢复。手动经过目的地不会将它标记为完成。
- 停机条件尚未解除时不能继续。

## 完成、无路和故障

| 显示状态 | 可以怎么操作 |
| --- | --- |
| 已到达 | 只查看结果，不能选点。按返回进入编辑，再选下一次任务 |
| 无路 | 保留目的地并等待新路线；可按返回暂停，再返回取消 |
| 导航暂停 | 确认继续；返回取消任务并退出交互 |
| 控制故障 | 排除问题后确认重试当前目的地；返回取消 |

完成后按返回进入编辑，会清除旧任务点，准心回到当前位置，辅助菜单选中“确认路径点”。编辑时再按返回，退出到左侧页面浏览。

取消会清除本次目的地；暂停会保留进度。完成、暂停、取消和手动驾驶均不清地图、不重置定位原点。

## 状态切换

| 当前状态 | 操作或事件 | 下一状态 |
| --- | --- | --- |
| 浏览 | 选择避障导航并确认 | 编辑 |
| 编辑 | 添加目的地后开始 | 运行 |
| 编辑 | 返回 | 浏览 |
| 运行 | 确认 / 返回 / 切手动 / 停机条件 | 暂停 |
| 暂停 | 切回光标档并确认，停机条件已解除 | 运行 |
| 暂停 / 控制故障 | 返回 | 浏览，任务取消 |
| 运行 | 所有目的地完成 | 完成 |
| 完成 | 返回 | 编辑，新任务 |
| 运行 | 控制器报告故障 | 控制故障 |
| 控制故障 | 确认重试 | 运行，仍执行当前目的地 |

无路时仍在等待路线，不会跳过目的地。灰色辅助项不可操作。板载 S3 强制切页会取消任务；S2 是全局清零，应停稳并退出任务后使用。

## 规划窗口整定

参数整定页最后一行“规划窗口”默认 5，范围 2～64，步长 1。CH2 上下选行，CH4 左右调整，CH5 下恢复默认；手动档不可修改。新值从下一轮规划生效，复位后恢复 5。它控制内部短段长度，默认每段最多相差 4 格；同向中间点不会要求小车逐点停车，控制器仍接收最远同向目标。
