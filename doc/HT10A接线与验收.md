# HT10A接线、参数与验收

核对：2026-10-28。应用映射由`rtl/rc/ht10a_input.v`和顶层`u_rc`定义，本表是整车接线入口；模块独立例程使用自己的映射，不能直接覆盖本车。

## 六路PWM接线

接收机CH号与转接板J6槽位不同。J6仅列信号，电源单独接合适接口并共地，沿用现场已确认的电气接法。

| 接收机 | 功能 | 转接板 | 顶层位 | FPGA管脚 | J1正式Pin |
| --- | --- | --- | --- | --- | --- |
| CH4 | 左摇杆左右：转向 | J6.1 | i_rc_pwm[0] | D19 | 5 |
| CH2 | 右摇杆上下：油门 | J6.2 | i_rc_pwm[1] | E19 | 6 |
| CH5/SWA | 三档，下确认、上返回、中位无动作 | J6.3 | i_rc_pwm[2] | E18 | 3 |
| CH7/SWC | 两档，上手动、下光标 | J6.4 | i_rc_pwm[3] | F18 | 4 |
| CH6/SWB | AI录音，下拨开始、上拨结束 | J6.5 | i_rc_pwm[4] | F20 | 1 |
| CH8/SWD/select | 三档，上/下选择页面内选项 | J6.6 | i_rc_pwm[5] | F19 | 2 |

六路均接入整车有效性判定。CH1/CH3摇杆轴、VRA/CH9、VRB/CH10不用于本应用。J7继续保留ToF用途。

## 当前配置

| 项目 | 整车值/含义 |
| --- | --- |
| SIG_VALID_MASK | 111111；每路都需有效。通用模块默认011111仅供独立配置/测试 |
| STEER_REVERSE / THROTTLE_REVERSE | 1 / 0，顶层覆盖值 |
| CONFIRM_ACTIVE_LOW / MODE_REVERSE / AUX_SWAP | 0 / 0 / 1，现场确认的开关方向 |
| 轴中位/半行程/死区 | 1500/500/25µs；CH2、CH4可各自设置 |
| 合法脉宽与超时 | 900～2100µs、100ms；归一化杆位±1000 |
| 开关分类 | SW_LO_US=1300、SW_HI_US=1700、迟滞30µs、连续2帧确认 |
| 录音拨杆 | SWB低于1200µs为上拨结束，高于1800µs为下拨开始，连续分类确认 |
| 菜单拨动 | 归一化幅度超过400触发，回到±150内可再次触发 |

`ht10a_input.o_btn_select`为保留端口，来源CH6，整车不以它选择子菜单。用户操作中的select是CH8，对应`o_aux_up/o_aux_down`。

## 交互及接管

- 光标挡：摇杆选择左侧菜单，SWA确认切页；页面进入交互后按该页规则操作。手动挡下页面交互屏蔽，摇杆归底盘。
- SWC手动由FPGA立即撤销自动输出。`manual_takeover`至少制动200ms，四轮增量在3个新采样窗口均不超过±2计数且双摇杆回中，才交给手柄；`rc_drive_guard`随后维持回中解锁状态。
- 手动后回光标不自动恢复导航或AI作业。AI总开关、当前功能及任务页保留，需明确确认或新的SWB录音手势。
- AI总页CH8选择四功能、SWA激活。SWB进入页面、换功能或恢复后先上拨再下拨，最长录音30秒，保持下拨不会重复录音。
- 巡检任务页CH8切三视图；地图SWA打开选点操作面板。返回、暂停、取消及多点继续见[巡检指南](AI视觉巡检.md)。

急停、遥控失效、堵转和模式切换的底盘处理均由FPGA完成。接收机仍输出合法PWM不等于射频在线，关发射机时的failsafe输出需单独实测。

## 现场复核

1. 按表逐槽核对CH与引脚；原有六路输入保持，不套用独立LED例程接线。
2. 检查CH4只改变转向、CH2只改变油门；记录中位、端点、死区和各轮方向。
3. 逐项验证CH5确认/返回、CH7手动/光标、CH8选择、CH6录音。方向有误时修改对应配置并重建，不改变通道语义。
4. 检查回中解锁、手动接管、回光标不自续、断单路PWM、发射机关闭及恢复行为。
5. 记录所加载位流、供电和测试结果；历史独立例程、软件回归与整车运动验收分别记录。
