# 运动桥生产接入与验证（2026-10-24）

本次以共享仓库生产整车 `origin/main` 的 `ec759b1` 为基线，只接入语音运动桥。保留既有 RC/J6 通道、UART 引脚、雷达/原导航/安全链和 OV5640→DDR3→HDMI 采显链。实验相机 `camera_fx2_stream/direct` 源码独立交付，不在生产顶层实例化，不增加 FX2 引脚或时钟。

## 连接

```text
原 UART RX → uart_command_router ┬→ uart_cmd_rx（ASCII PID/清零）
                                └→ voice_motion_bridge（MOT1）
原 obs/free 导航选择 ───────────────┐
语音 owned/valid/center/diff ────────┴→ voice_nav_arbiter → 原 chassis_ctrl → 原电机闭环
真实 IMU sample + 初始化/标定健康 ─────→ 语音转角检测
手动 / 急停 / 遥控失联 / 堵转 / 规划急停优先
```

生产源文件由 `scripts/vendor_sources.tcl` 递归取得应用 RTL，`deps/modules.list` 增加 `voice_motion_bridge`。不需要拷贝 Claude 实验候选的顶层、引脚表、相机缓冲模块或旧网表。

## 必要修复

- 完整 12 字节 MOT1 与 ASCII 调参隔离；CRC `0x78` 等不会变成 `x` 清堵转。二进制开始清理半条 ASCII 输入，已完成 PID 保留。两个解析器均有 20 ms 字节超时。
- 按 `o_owned` 选源。语音 STOP、完成、看门狗、IMU 故障后持续零目标，不泄漏原导航的非零速度。安全门关闭时不执行动作，恢复也不恢复旧动作。
- 用真实 `imu_data_valid_d1` 而非常使能 `yaw_valid` 检查新鲜度。转弯前要求初始化/标定成功，转动中健康失效或 200 ms 无真实样本即停车。
- 累积角度全部有符号，正确处理 ±180° 回绕、360° 和反向一度扰动；新命令优先于同拍旧动作结束。
- 未知、CRC 错误、零速、零角、越界时长/角度、无健康 IMU 的转角请求不续看门狗。命令合同仍为 `host/semantic_nav/mot1.py`，没有新回执协议。

## 本版边界

生产顶层 `voice_nav_release_ready=0`，所以语音“开启巡航”没有开通实际航点任务。桥会拒绝释放并保持停车；没有伪造航点、恢复或完成回执。

一旦语音取得所有权，原 UI 导航被保持。原 UI 的继续/重新开始不会隐式释放；本版只有整车复位清除语音所有权，或未来实现经明确确认的导航释放条件。手动遥控继续独立优先。不要在仍持有语音所有权时期待自动回到旧路线。

协调器本轮新增正式 MOT1 执行后端：文本/ASR 同入口，与 FAM1 共用唯一串口，整帧排队、独立心跳、停止优先、旧动作清理；默认关闭，需现场 `live_commissioned=true`。现有 MOT1 没有任务级回执，串口写入成功、CRC 正确和主机计时都不是实车动作成功/停车证明；状态保持 `device_reply_verified=false`、`action_complete_verified=false`、`physical_stop_verified=false`。ToF 仍是原生产工程的预留（恒 0），不得宣称已有 ToF 实物防撞。接入细节见`doc/语音到FPGA运动执行接入_20261024.md`。

## 验证

`sim/run_sim.ps1 -Simulator Icarus` 新增：

- `voice_motion_bridge`：有符号转角、限幅、freshness、所有权、看门狗、同时钟优先级、截断恢复。
- `uart_command_router`：九命令 × 256 序号共 2304 合法 MOT1 帧；坏 CRC/未知命令/帧内 ASCII/截断/部分 magic/半条 PID/积压队列 abort 恢复。
- `voice_motion_integration`：真实生产 router、bridge、arbiter 在持续非零导航背景下验证完成/STOP/看门狗/手动/急停/IMU故障后保持停车，以及两个解析器截断后的首帧恢复。

另将既有 `nav_sys_tb.v` 和 `odom_tb.v` 的局部变量 `before` 分别重命名，消除 Icarus SystemVerilog 保留字冲突，测试逻辑不变。`sim/run_sim.ps1` 保持 UTF-8 BOM。

完整整车回归、Gowin 重新综合/PnR、位流 SHA 及发布状态由同轮交付证据记录。模块仿真、综合和 PnR 都不等于实车通过。

## 队友现场顺序

使用同轮整车构建的 SRAM-only 位流，不写 Flash。车轮架空，保留硬件急停和遥控；先无动作核对 UI、RC 与 IMU，再明确选择受控语音命令并从前进/STOP开始，随后低速转角与故障停车。标定偏航方向、轮速、漂移和停止容差后才能低速落地。没有硬件时不报告这些项目完成。
