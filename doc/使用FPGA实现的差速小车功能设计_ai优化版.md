# 差速小车实现说明

核对：2026-11-09。本文说明现行实现和仍需完成的工作；[用户原始功能设计](使用FPGA实现的差速小车功能设计.md)保留原文，后续明确交互修订按当前操作说明执行。实现参数在[参数总表](参数总表与待定清单.md)，部署/实测在[交接单](交接单.md)及专题验证，不在此重复维护历史数值。

## 平台与硬件边界

主工程为ACG720/GW5AT-138B、50MHz，HDMI1024×600。管脚以本项目`constr/falcons.cst`与[厂商手册](ACG720_引脚接线手册_RevI.pdf)、[管脚表](<高云 ACG720-138&60K通用管脚分配表.xlsx>)逐针核对，时序约束成对使用`falcons.sdc`。

| 部分 | 现行接入 |
| --- | --- |
| 底盘 | D24A四驱差速；电机输出/编码器使用原J4/J5排线及STBY仲裁，按实际约束核对 |
| 遥控 | J6六路PWM，CH4/2摇杆、CH5确认返回、CH7手动光标、CH6录音、CH8/select |
| IMU | 原J2 SPI接口，初始化/采样/偏航链在FPGA |
| 雷达 | RX为C14；不能复用IMU CS的A15 |
| FPGA相机 | OV5640 DVP，DDR帧缓存及本地相机页面，显示180°翻转 |
| RK相机 | 独立UVC直接接RK，用于全部AI视觉，按设备身份发现 |
| RK控制/高速 | CH340串口115200/8N1 + FX2 USB；高速为RK Host至FPGA J5 Type-C，JTAG另接 |
| ToF | 项目内驱动与独立例程已有，整车尚未例化，tof_estop=0 |

扩展排针与USB连接器的J编号来自不同图表，不按同名猜接。电平/供电沿现场确认接法，外设共地、功率余量和满载供电仍需实测记录；不把手册额度或独立例程结果写成整车已验收。

## 实现分层

```text
FPGA：传感器/采显 → 位姿与雷达地图 → Dijkstra/控制 → 底盘仲裁 → 四轮PID/驱动
RK：独立UVC/语音 → 模型 → AI任务/视觉障碍/页面/记录 → 当前目标与内容帧
```

- 可复用模块直接维护项目内vendor；应用适配在rtl，RK/电脑软件在host。各包用途与源码入口见[模块速查](模块库接口速查.md)。
- 运行参数、点表与任务所有权按基础导航和AI任务分离；RK断连后基础相机、雷达、导航、整定、手动及必需字形都由FPGA完成。
- UART唯一所有者分别路由ASCII调参、MOT1语义动作和巡检保留事务；FAM1独立回放工具不等于生产任务接口。

## 功能与页面

| 功能 | 当前行为与入口 |
| --- | --- |
| 估计 | 编码器窗口测速、IMU偏航及窗口中点里程积分；初始车头+x、左+y、逆时针yaw正 |
| 电机 | 四轮速度PID、左右差速、堵转/急停/遥控仲裁；正center前进、正diff左转 |
| 数据页 | 小车俯视图、四轮rpm、航向、角速度、中心速度与航位 |
| 摄像头页 | 仅FPGA相机本地画面，不上传RK |
| 雷达页 | FPGA实时地图，256×256、50mm/格 |
| 避障导航 | 独立点表、八方向Dijkstra、居中/路线复核/前探、nav_point_ctrl执行 |
| 非避障导航 | 原nav_free_ctrl/nav_ctrl，保留间断/连续寻点用于调试 |
| 参数整定 | 16项RAM参数，摇杆选行/调值，退出只退编辑态，掉电回默认 |
| AI模块 | 语义导航、目标识别、聊天机器人、视觉巡检四个独立入口 |

上电默认数据页。光标挡摇杆选择左侧菜单、SWA确认切页；页面进入交互后冻结左菜单。AI标签使用居中大字和蓝底黄字，字库、动态数值容量见[参数总表](参数总表与待定清单.md#显示与存储)。完整交互见[上板操作](上板指南_v1.md)和[AI交互](AI模块页面与遥控交互_20261024.md)。

## 手动优先与任务恢复

SWC手动由FPGA立即撤销自动输出，经过原停车/回中守卫交给手柄；AI保留总开关、当前功能和任务页，回光标不自动续跑。SWA明确继续当前任务或SWB新录音后处理下一作业。急停、遥控失效、断连和定位重置的撤权不依赖模型响应。

底盘center/diff为窗口计数，位置mm、角度0.01°；RK地图坐标为米/弧度。接口量纲和方向需成对核对，不能以屏幕位置、框面积或串口发送成功代替真实距离/执行回执。

## 视觉巡检

RK管理有序路径点，每次调用现有FPGA导航一个目标，并下发`inspection.cruise_speed_mm_s`设置的巡航速度，默认300mm/s；途中检出新目标后STOP回执、等0.3秒、三帧H定位、提交视觉raw/cost后继续当前点。完成最后一点后按最新地图返回实际起点，允许换路。FPGA巡检执行器不再附加±120限幅，基础导航保持原参数；除相机≤0.3秒延迟假设外信任其他传感器数据，不加入精确对时或高精度验收框架。

AI视觉全部来自RK独立相机。当前1280×720、focus260、去畸变H和40cm起有效凸包已部署；雷达探不到的贴地物体由视觉生成障碍层，不直接改写雷达存储。四类目标检测、目标播报和两路10Hz全程录像由RK完成；检测阈值及连续确认参数见[参数总表](参数总表与待定清单.md#rk巡检演示常数)。

操作、接口、演示常数和已测/待测分别只在[巡检指南](AI视觉巡检.md)、[录像管理](AI巡检录像与报告.md)、[验证记录](AI巡检验证记录.md)维护。

## 时钟、存储与时序

系统50MHz、像素49MHz、FX2约30MHz，DDR使用现有IP时钟与唯一控制器。相机和AI帧银行地址隔离，通过异步FIFO、稳定元数据握手及实际读响应排空跨域，按帧边界发布。图层使用同步RAM及完整CRC提交，不让规划器读半张新图。

新增FPGA逻辑从设计起寄存/分拍，避免地址换算、宽数据选择、CRC及使能组合串联。时序和资源以对应输入的实际整车PnR为准；当前同域通过仍有既有跨域端点，不能宣称全部闭合或用旧构建签核新源码。
