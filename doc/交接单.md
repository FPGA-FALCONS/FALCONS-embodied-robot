**两个同名陷阱**：

- 顶层 `run_en`（遥控解锁，喂 `chassis_ctrl.i_enable`）≠ `chassis_ctrl` 内部 `run_en`（= `i_enable & ~i_estop & ~any_stall`）。后者含 `~any_stall`，**任一路堵转锁存 → 整车 `o_enable` 变 0**。
- **堵转锁存只能 S2 键或串口命令清除**；堵转根源往往是 **TB6612 的 VM 动力电源没接**。

  功能提交历史：`7a3fdc3`（odom 落地 + 里程标定 + 上电默认页）→ 其后一条为
  **odom 位移积分改窗口中点**（`工作记录.md` §54）。
  ★ 本行**不锁死当前 HEAD hash**，避免文档因自身提交而立刻过时（这条是"一次任务一次提交"的前提）。
  ★ 工作区仍有一处**故意排除**的改动：`vendor\...\acg720_tof_debug\tof_debug.cst`（队友示例工程的本地调试改动，非本工程产物）。
- 删除 / 回退 / 覆盖 / 改工作区外文件 / 改需求原文，都要先拿到明确指令。
- `.ps1` 必须 **UTF-8 with BOM**；`.tcl` / `.v` / `.md` 无 BOM；读中文显式指定 UTF-8。
- 改 vendor 模块 → 先跑 `sim\run_sim.ps1` 回归。
