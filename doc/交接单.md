## 五、关键约定（改错了会全局崩，先看）

| 约定 | 当前值（快照） | 真源 |
| --- | --- | --- |
| **需求原文最高优先级** | 实现侧**不擅自改** | `使用FPGA实现的差速小车功能设计.md` |
| **接线真源** | CH2 油门 / CH4 转向 / CH5 确认 / CH7 select / CH6 模式 / CH8 闲置；**接收机 CH ≠ J6 针号** | `HT10A接线与验收.md` §2 |
| **信号有效掩码** | `SIG_VALID_MASK = 6'b011111`（排除闲置 bit5）—— **写错会让 `run_en` 恒 0、车不动** | `ht10a_input.v` / `参数总表` |
| **方向与极性（§35 现行）** | `INV_DIR_VEC=4'b1111` / `ENC_INV_DIR_VEC=4'b0101` / `STEER_REVERSE=0` / `THROTTLE_REVERSE=0` / `RPM_DISP_INV=4'b0000` | `falcons_top.v` 顶部 localparam + `u_rc` 例化 |
| **堵转阈值（已放宽）** | `100 / 40 / 400 / 4000`（起步宽限/判定窗口/占空比门槛/净位移门槛） | `falcons_top.v` 的 `u_motor` 例化 |
| **PID** | `P=0 / I=64 / D=0`（Q8，纯积分，**未整定**） | `参数总表` / `chassis_ctrl.v` |
| ~~未解矛盾~~ **已结案** | 当年"改油门却让转向翻转"的疑案：根因是 **四个通道与轮位整体错位**（**A = 右后 / B = 左后 / C = 右前 / D = 左前**），不是取反参数的锅 | `工作记录.md` §26.5（已标注结案）→ §34 → §35 |

**两个同名陷阱**：

- 顶层 `run_en`（遥控解锁，喂 `chassis_ctrl.i_enable`）≠ `chassis_ctrl` 内部 `run_en`（= `i_enable & ~i_estop & ~any_stall`）。后者含 `~any_stall`，**任一路堵转锁存 → 整车 `o_enable` 变 0**。
- **堵转锁存只能 S2 键或串口命令清除**；堵转根源往往是 **TB6612 的 VM 动力电源没接**。

## 八、安全红线（全局规则 + 本工程）

- **push 需明确指令**；`main` 与 `origin/main` **已同步于 `0635d73`（摄像头接入 + 上板实测）**，`ahead 0 / behind 0`（数字以 `git status -sb` 为准，本行随每次推送更新）。
- 删除 / 回退 / 覆盖 / 改工作区外文件 / 改需求原文，都要先拿到明确指令。
- `.ps1` 必须 **UTF-8 with BOM**；`.tcl` / `.v` / `.md` 无 BOM；读中文显式指定 UTF-8。
- 改 vendor 模块 → 先跑 `sim\run_sim.ps1` 回归。
- 烧录纪律：先 `-Action Sram` 验证，再 `-Action Program` 固化。
- USB 下载器偶发断开（`programmer_cli` 退出码 48/50，`--scan-cables` 扫不到），重新插拔 USB 即可。
- 编译/仿真/烧录都要在**工程根目录**执行（脚本用相对路径）。
