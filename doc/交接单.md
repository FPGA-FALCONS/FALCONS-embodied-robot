| --- | --- | --- |

| **接线真源** | **CH4 / CH2 = 摇杆**，**CH5 三档（下=确认 / 上=返回）**，**CH7 两档（上=手动 / 下=光标）**，**CH8 三档（辅助菜单上/下）**，CH6 闲置；**接收机 CH ≠ J6 针号** | `HT10A接线与验收.md` §2 |

| **★ 坐标约定** | 初始车头朝 **+x** / 左侧为 **+y** / **左转（逆时针）航向角增大** ⇒ `YAW_SIGN = +1`。**只有两个坐标系：odom 相对系（点表）与车体系（`ahead` 前+ / `left` 左+），没有世界系。** ★ 与 `odom.v` 的投影**必须成对改** | `falcons_top.v` 的 `YAW_SIGN` + `odom.v`；§55 |
| **方向与极性** | `INV_DIR_VEC=4'b0000` / `ENC_INV_DIR_VEC=4'b1010` / `STEER_REVERSE=1` / `THROTTLE_REVERSE=0` / `RPM_DISP_INV=4'b0000`。★ 电机与编码器**必须同时取反**，`STEER_REVERSE` 也要单独取反 | `falcons_top.v` 顶部 localparam + `u_rc` 例化 |
| **★ 差速符号链（调 PID 必读）** | `chassis_ctrl.v:148-149` `tgt_left_r <= clamp_delta(center_r - diff_r)`、`tgt_right_r <= clamp_delta(center_r + diff_r)` ⇒ **`diff > 0` → 左轮慢 → 左转（CCW）→ yaw 增大**。所以 `diff_cmd = +(kp·e_psi + ki·∫ − kd·ω)`，**不要再加负号**（加过，是正反馈自旋） | `chassis_ctrl.v` / `nav_ctrl.v` |
| **★ 积分限幅** | 默认 **90**（= `MAX_DIFF_CRUISE/2`）。原来 400 比巡航 180 大 2.2 倍 ⇒ 积分饱和、PID 退化成 bang-bang，是**直线摆头的真因**。3° 时 `24+90=114<180`；8° 时 `65+90=155<180` | `tune_ctrl.v` 第 9 行 / `nav_ctrl.v:416-417` |
| **堵转阈值** | `100 / 40 / 400 / 4000`（起步宽限/判定窗口/占空比门槛/净位移门槛） | `falcons_top.v` 的 `u_motor` 例化 |

- 顶层 `run_en`（遥控解锁，喂 `chassis_ctrl.i_enable`）≠ `chassis_ctrl` 内部 `run_en`（= `i_enable & ~i_estop & ~any_stall`）。后者含 `~any_stall`，**任一路堵转锁存 → 整车 `o_enable` 变 0**。

## 七、常用命令（工具路径真源在 `tools\lib_paths.ps1`）

```powershell
powershell -ExecutionPolicy Bypass -File sim\run_sim.ps1      # 仿真（19 台 / 2186 项）
powershell -ExecutionPolicy Bypass -File tools\build.ps1      # 整车综合（产物 impl\pnr\falcons.fs，约 7~9 分钟）
# ★ 只想重跑布局布线（RTL 没改、只改约束）：tools\build.ps1 -Tcl build_pnr.tcl（约 6.6 分钟）
#   只重跑综合：build_syn.tcl（约 2 分钟）
# 手柄独立诊断位流（输出到独立目录，不覆盖主位流）
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Tcl build_rc_led.tcl -ArtifactDirectory 'impl/rc_led_test/impl/pnr'
powershell -ExecutionPolicy Bypass -File tools\program_flash.ps1 -Action Sram     # 只下 SRAM（掉电失）
powershell -ExecutionPolicy Bypass -File tools\program_flash.ps1 -Action Program  # 固化（★ 有 yes 交互确认）
python tools\gen_font_rom.py                                 # 改字表后重生成字库
python tools\preview_tune_page.py --out doc\img\x.png        # 参数页效果图（真实字库渲染）
python tools\check_pin_constraints.py                        # 引脚逐针复验
```

★ **`program_flash.ps1` 的 `-Action Program` 有 `Read-Host '确认？(yes/N)'`，非交互调用会读到空串并打印「已取消。」后 `return`（退出码仍是 0，极易误判为成功）**。非交互调用写法：

```powershell
"yes" | powershell -ExecutionPolicy Bypass -File .\tools\program_flash.ps1 -Action Program
```

## 八、安全红线（全局规则 + 本工程）

- **push 需明确指令**。当前 `origin/main` = `7c76048`，本地 `HEAD` = `9956baa`，**领先 1 个提交、未推送**。
  ★ 本行**不锁死 HEAD hash**，以 `git status -sb` / `git rev-list --left-right --count origin/main...HEAD` 为准。
- ★ 工作区有三处**故意排除**、永不提交的内容：`vendor\...\acg720_tof_debug\tof_debug.cst`（队友示例工程的本地改动）、
  `doc\img\menu5_default.png`（与 `page0.png` 逐字节相同）、`log\`。**提交时用显式文件列表，不要 `git add -A`。**
- 删除 / 回退 / 覆盖 / 改工作区外文件 / 改需求原文，都要先拿到明确指令。
- `.ps1` 必须 **UTF-8 with BOM + CRLF**；`.tcl` / `.v` / `.md` 无 BOM + LF；读中文显式指定 UTF-8
  （`Get-Content` 会按 GBK 解码，必须用 `[IO.File]::ReadAllLines($p, [Text.Encoding]::UTF8)`）。
- 改 vendor 模块 → 先跑 `sim\run_sim.ps1` 回归。**`impl\` 是 gitignored，位流不在库里，队友必须自己重新综合。**
- 烧录纪律：先 `-Action Sram` 验证，再 `-Action Program` 固化。
- USB 下载器偶发断开（`programmer_cli` 退出码 48/50，`--scan-cables` 扫不到），重新插拔 USB 即可。
- 编译/仿真/烧录都要在**工程根目录**执行（脚本用相对路径）。
- ★ **`vsim` 必须加 `-novopt`**，否则默认 vopt 报 `# Optimization failed`（exit 12）。
- ★ **`vlog` 单独编译 `falcons_top.v` 不能验证顶层语法**（会报一堆 pre-existing 的 `vlog-2730` / `vlog-2388`），顶层语法只能靠综合验证。
