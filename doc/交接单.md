## 接线、控制及不能混淆的接口

| 项目 | 现行依据 |
| --- | --- |
| J6 | CH4/CH2摇杆、CH5/SWA确认返回、CH7/SWC手动光标、CH6/SWB录音、CH8/select子菜单；完整针号见[HT10A](HT10A接线与验收.md) |
| 有效掩码 | 整车`111111`；模块默认`011111`用于独立验证，不能拿默认值覆盖整车 |
| 手动优先 | SWC立即撤销自动输出，FPGA本地停车/回中接管；AI留页保留总开关，回光标不自动续跑 |
| 地图坐标 | 初始车头+x、左+y、逆时针yaw正；RK内部米/弧度，线协议毫米/0.01度 |
| 相机H坐标 | 测量点右/前厘米，投影后转换前/左米；focus260、1280×720绑定当前H |
| USB高速 | RK USB-A Host至FPGA J5高速Type-C；另保留CH340控制串口。高速容器AIF1用于显示/地图/图层，不是FIMG旧相机上传协议 |
| 运动接口 | 语义短运动用MOT1；视觉巡检用保留MOT1事务封装和真实状态回执；FAM1找物协议仍是参考/回放能力，不能等同已接巡检 |
| ToF | 独立包可用，整车`tof_estop=0`，没有真实ToF急停能力 |
| 字库/动态数值 | 本地字模252槽；数值14字段×5字符，顶层RAM128字节。旧“12字段只余4槽”已失效 |

引脚仅按`constr/falcons.cst`与硬件手册核对；不要把厂商USB连接器J5和扩展排针同名编号混用。原电机/编码器极性、轮位与量纲见[参数总表](参数总表与待定清单.md)，不据视觉画面旋转改物理方向。
