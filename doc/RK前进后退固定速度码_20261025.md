# RK前进后退固定约300mm/s

所有应用前进/后退指令统一使用MOT1速度码229，理论目标299.76mm/s；由RK的`motion_intents.DRIVE_SPEED_CODE`独立固定，不读取巡检速度配置。普通、定时及通过距离策略的指令均执行此策略，文字、ASR、AI页面、独立`semantic_nav/send_motion.py`和正式发送后端一致。

换算：229×4=916计数/10ms，轮径64mm、每轮61440计数/转，线速度为916×100÷61440×π×64≈299.76mm/s。这是闭环设定值，实际地面速度尚需实测。

`voice_motion.settings.drive_speed`报告速度码229；`voice_motion.speed`仅配置转向/旋转。普通定时、STOP和心跳机制保持原样。距离指令支持0.05–2m，直接按0.3m/s估算，超过单帧5s由RK分段，不要求实测标定开关；不代表实际到达已验证。

策略版本`zh-motion-drive300mms-distance-5`。仅修改RK应用，无需修改协议、RTL或烧录FPGA。2026-10-25的速度码30证据保留在`doc/evidence/rk_drive30_20261025/`，属于历史记录。
