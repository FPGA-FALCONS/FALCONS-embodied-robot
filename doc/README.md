维护时核对内部链接、源文件/通配符引用及关键参数；关键词检索只定位问题，不对“30、14、0.5”等数字全局替换。模块独立例程与整车验收分开，vendor维护遵循[ORIGIN](../vendor/ORIGIN.md)。
