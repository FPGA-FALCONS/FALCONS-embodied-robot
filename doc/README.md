## 写文档的两条纪律

1. **数字要有出处**：实测值（如手转车轮一圈 ≈ 61657 计数、25% 占空比 ≈ 72 rpm）要写清
   测量条件；理论估算与实测分开写。
2. **区分"已验证"与"预期"**：`class\car_fpga` 的上板结论都是在**旧接法（飞线）+ 旧约束**下测得的；
   改成主板排线直连后，**"排线直连 + 新约束"这个组合还没有上过板**。
   迁入文档时要保留这个状态标注，不要让人误以为已经在新接法下验证过。
