## 维护规则

根README只做摘要；交接单汇总状态，参数总表说明来源，验证记录列时间线。实际运行值以代码、顶层参数、RK配置与加载位流为准，不以文档覆盖实现。改现行口径直接替换，改验证结论须有对应记录；带日期的操作文档可继续维护，归档报告则保持当时范围。

原始证据、测量JSON和第三方资料不改写。新增过程记录写到对应阶段或模块验证条目，避免再创建一套重复的“最新状态”。文档路径变化同步模块README、链接锚点和源码交付清单；模块独立验证与整车验收仍分开。
