# 使用FPGA实现的差速小车

包含的功能：

1. imu数据读取与偏航角积分。已完成imu读取和积分的模块，可直接使用。
2. 电机闭环，已完成电机pwm驱动的模块，可直接使用。要求四个电机单独闭环。小车行驶中，左侧两轮同速，右侧两轮同速。左右侧差速实现转向。
3. 航位计算。使用编码器采集的电机转速数据，用Imu解算的航向角进行矫正（差速车可能有侧向打滑），计算当前航位并显示在屏幕上。
4. 使用HDMI输出画面和ui到屏幕。使用手柄来控制屏幕。具体屏幕ui和控制功能在后面给出。屏幕显示模块已完成，可直接使用。
5. 摄像头画面采集，显示到屏幕上。目前阶段无需进行画面识别，仅显示，但后期有外接RK3588进行图像处理的需求，可预留位置。
6. tof测距，tof模块装在车前端，感应距离50cm左右，仅用作紧急刹停。当前方障碍物距离小于一定值，控制车辆紧急刹停。
7. 雷达模块，建2D平面图，实现自主避障，该避障功能在后续的导航功能中体现。
8. 自主导航与路径点导航。可在雷达建图上选定目标点或路径点，小车自主规划路径经过路径点并到达目标点，其中要自主避障和绕障。已完成雷达数据接收模块以及建图模块。
10. 遥控器控制。遥控器有两个摇杆（分别控制前后、左右）以及若干按钮和开关。当模式开关选择接管车辆控制时，通过遥控器直接控制车辆行走以及转向，原先正在执行的任务暂停；当模式开关选择控制屏幕时，摇杆控制屏幕菜单选项或光标移动等，按钮来确认/select，来选择特定的自动化功能和任务或展示数据面板。已完成遥控器数据接收模块。按键分配：CH2与CH4为摇杆（分别对应前后、左右）；CH5为三档开关，下拨为确认、上拨为返回；CH7为两档开关，上拨为手动挡（接管车辆控制）、下拨为光标挡（控制屏幕）；CH6为两档开关，暂不使用（预留）；CH8为三档开关，上拨为辅助菜单向上切、下拨为向下切（无辅助菜单的页面无效果）。

# 屏幕ui和交互设计

左侧占屏幕约1/5或1/6宽度为菜单列表，菜单选项包括：运行数据显示；摄像头画面；雷达建图展示；避障导航；非避障导航。使用摇杆上下拨动来切换选项。初始化默认选中运行数据显示并确认。

### 运行数据显示

选中该项时，菜单右侧画面中心为一辆小车俯视示意图，小车前端（即画面上方）实时显示车辆朝向，即航向角，四个轮子旁实时显示每个轮子编码器读数，以及右侧单独竖向排列显示车辆角速度、中心速度、航位等信息。该页面不做交互设计，不占用摇杆功能，使用摇杆仍可上下切换菜单选项。

### 摄像头画面

选中该项并确认时，菜单右侧全部画面实时显示摄像头采集的画面。该页面不做交互设计，不占用摇杆功能，使用摇杆仍可上下切换菜单选项。

### 雷达建图展示

选中该项时，菜单右侧全部画面实时显示雷达的2D建图画面，以及在页面右下角显示车辆方向和航位。该页面不做交互设计，不占用摇杆功能，使用摇杆仍可上下切换菜单选项。

### 避障导航

选中该项时，菜单右侧画面实时显示雷达的2D画面建图（地图）。点击确认键进入路径点导航设置状态（但菜单栏不消失，而是变暗。画面整体布局不变，此时摇杆不可再操作菜单，需通过遥控器上独立的返回按键才返回上一级），此时地图的中央出现一个准心，地图右侧浮空显示一个辅助菜单（包含“确认路径点”、“撤销路径点”、“开始导航”、“清除所有路径点”，初始默认选中“确认路径点”，按手柄上的select键依次切换）。通过遥控器摇杆控制准心上下左右移动，地图不动，以实现准心与地图相对运动，来选择路径点位置。将准心移动到目标位置后，点按遥控器的确认键确认该路径点，随后地图上该位置出现一个圆点标志，随后继续下一个路径点的设置。直至所有路径点设置完毕，选中“开始导航”并确认，结束路径点选择状态并开始导航任务，任务执行过程中，“开始导航”选项变为“暂停任务”，选中并确认时，停止导航任务。该页按返回键时：若当前不在导航任务中，返回菜单选择（此时菜单不再冻结、可正常切换）；若正在执行导航任务，则暂停任务、状态栏显示“导航暂停”，再按一次确认键继续导航任务、状态栏显示“导航中”。

### 非避障导航

选中并确认该项时，菜单右侧画面显示一个坐标系（纵向正负5m，水平方向与纵向比例相同，只画坐标轴不画网格，坐标轴延伸到画面边缘），x轴正方向朝右，y轴正方向朝上，原点在该页面（不含菜单栏）竖直方向1/2、水平方向1/4处。车的位置以一个直径6px的绿点表示，同时绿点上出现一个白色十字准心。右下角靠边显示一个辅助菜单（包含“确认路径点”、“撤销路径点”、“间断寻点”、”非间断寻点“、“清除所有路径点”，初始默认选中“确认路径点”，按手柄上的select键依次切换）。此时摇杆的移动不控制菜单项，而是控制该准心上下左右移动。屏幕右上角以24px密集数字实时显示准心的实时坐标（x，y，竖排显示，精度0.01m，显示方式与数据显示页相同）。当按下确认键时，（若辅助菜单选中“确认路径点”），屏幕记录下准心位置（表现为在当前准心位置上画一个白色小圆点，直径4px）。多次按下确认时，都记录下准心位置。当辅助菜单选中”间断寻点“并按下确认键，开始间断寻点模式；当辅助菜单选中”非间断寻点“并按下确认键，开始非间断寻点模式。该页按返回键时：若当前不在导航任务中，返回菜单选择（此时菜单不再冻结、可正常切换）；若正在执行导航任务，则暂停任务、状态栏显示“导航暂停”，再按一次确认键继续导航任务、状态栏显示“导航中”。

间断寻点：任务开始后，车原地旋转对准第一个点，然后走到该点，停止后旋转对准下一个点然后直线寻点，直至寻完全部点。

非间断寻点：点只作路标，到点后不减速。

# 要求

通过遥控器和屏幕实现交互，来控制小车运动和执行任务。要求各模块之间尽量相互独立且解耦，封装程度高。
