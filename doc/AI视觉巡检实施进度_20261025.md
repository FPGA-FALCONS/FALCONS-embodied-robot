# AI视觉巡检分阶段实施

按用户2026-10-25要求，在 `codex/ai-visual-inspection` 独立分支逐阶段提交，提交说明使用中文；每次提交前拉取共享主线，保留无关本地改动。各阶段只提交其代码、测试和必要文档，不自动推送或烧录。

## 已确定的实施边界

- 复用FPGA现有雷达建图、八方向导航和底盘闭环；RK承担视觉、地面定位、任务调度、图层和内容渲染。
- FPGA摄像头只供原摄像头页，RK视觉只读取RK独立UVC相机。
- 摄像头及其他外设的USB端口不是固定接线。优先以设备VID/PID/序列号/功能选择，只有存在歧义时才使用用户配置的物理路径；禁止自动选择video0或任意同类设备。插拔后重新核对身份与模式。
- 用户提供镜头6mm、视场角约60°、低畸变，作为设备描述保存。它们不是精确内参；不据此捏造焦距像素、零畸变、相机高度或俯仰。
- 安装位置、角度、内外参与时效由后续实测完善。标定/运动条件未通过时，只允许观察、回放、编辑和预览，不授权巡检行驶。
- FPGA新增地图读取、版本切换、协议校验和显示通路从设计起采用寄存器、同步RAM、握手及分拍计算，不将完整包CRC、地址计算和输出选择串成大组合路径。
