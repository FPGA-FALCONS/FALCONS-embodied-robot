| # | 检查项 | 为什么 |
| --- | --- | --- |
| 1 | **灰排线按 Pin 号核对两端，确认 Pin1** | 母头与公针是镜像的；插反 = 整排错位，综合完全查不出来 |
| 2 | **雷达 RX 接 C14（J3.3），绝不接 A15** | A15 = J2.6 = IMU `CS`，J1 与 J2 同网络，两个输出挂一起会"对打" |

| 6 | 遥控接收机接 **J6**（D19 E19 E18 F18 F20 F19）；**实际只用 5 路**（2 摇杆 + 确认 + select + 模式拨杆），**J6.6/F19（bit5）闲置** | 与 `constr\falcons.cst` 一一对应；**接线以 `doc\HT10A接线与验收.md` §2 为唯一真源**（接收机 CH ≠ J6 槽位标签）；bit5 已由 `SIG_VALID_MASK = 6'b011111` 排除在"信号有效"判定外，插不插都不影响开车 |

## 三、按键与 LED

### 板载按键（低有效）

| 按键 | 引脚 | 功能 |
| --- | --- | --- |
| **S0** | F15 | 系统复位 |
| **S1** | A20 | **停机锁存**（切换）：接管档内按一次停住、再按解除；切出接管档自动清 |
| **S2** | B20 | 编码器计数清零 + 堵转锁存清除 + 航向角清零 |
| **S3** | A21 | **备用翻页**（无遥控时用；同时移动"高亮项"与"已确认页"，避免两者不一致） |
| **S4** | B21 | **急停**（锁存切换）：按一次急停并停机，再按一次解除 |

### LED（高电平点亮）

| LED | 含义 |
| --- | --- |
| LED0 | 底盘正在输出（`chassis_running`） |
| LED1 | 急停锁存中 |
| LED2 | 任一路电机堵转 |
| LED3 | 遥控信号有效（**参与判定的 bit0~bit4** 都在刷新；**J6.6/bit5 闲置、已由 `SIG_VALID_MASK = 6'b011111` 排除，不参与判定**） |
| LED5:4 | 当前遥控模式（**两档**）：`00` 手动接管 / `01` 屏幕光标 |
| LED6 | 底盘使能（接管档 + 油门在中位 + 信号有效 + 非急停 + 未按 S1 停机锁存） |
| LED7 | 心跳（约 0.34 s 翻转一次，说明时钟在跑） |

> ★ **接线只以 `doc\HT10A接线与验收.md` §2 为准**（上表是摘要）。转接板 J6 的丝印 CH1..CH6

**开机自检**：上电后 LED3 应亮（遥控信号有效）、LED7 心跳闪烁、屏幕出现菜单。
若 LED3 不亮 → 接收机没通电/没对码/接错通道。

**开车步骤（2026-10-16 改）**：模式拨杆打到**手动接管**（LED5:4 = 00）→ **把油门杆回到中位**
（状态栏不再显示 `请回中位`）→ LED6 亮（底盘已使能）→ 推油门。
**不再需要先按 S1**；S1 现在是"停机锁存"。按 S4 随时急停。

> ★ **启动门禁 / 解锁守卫（2026-10-15 加；2026-10-16 合并后由 `rtl\rc\rc_drive_guard.v` 承担：`ARM_DEADZONE = 100`）**
> 底盘使能（`run_en`）的条件：**手动接管档 + 遥控信号有效 + 油门曾回到中位死区内**
> （`|throttle| ≤ 100`，即归一化 ±1000 的 10%）→ **解锁一次后保持**（之后推油门不会失能）。
> 目的：防止"上电时油门杆恰好停在半位，一切到接管档车就窜出去"。
> **撤销解锁**：切出接管档、丢信号、急停（S4 / ToF）、按 S1 停机锁存 —— 之后再运行要**重新回中**。
>
> | 现象 | 说明 / 怎么办 |
> | --- | --- |
> | 油门没回中位时切到"手动接管"档、底盘不使能，状态栏显示 `请回中位` | 正常 —— 这是门禁在起作用，把杆回中位即可 |
> | 想停车 | 按 S1（**停机锁存**，接管档内有效；再按解除）或按 S4（急停锁存）；把模式拨回**光标档**也会立刻停（`run_en=0`） |
> | 杆已回中却启动不了 | 接收机中位有偏差 → 调大 `rtl\rc\rc_drive_guard.v` 的 `ARM_DEADZONE`（顶层 `u_rc_guard` 例化给值） |
> | 轻轻碰一下就能启动 | 调小该值 |
>
> **★ 开车方式（2026-10-16 按需求方要求改过）**：**把模式开关打到"手动接管"档**（<1300 µs）
> 且**油门摇杆在中位**，底盘就处于使能状态 —— **不再需要先按 S1**（需求原文 §13：
> "当模式开关选择接管车辆控制时，通过遥控器直接控制车辆行走以及转向"）。
> - 油门不在中位时切到接管档**不会动**（状态栏显示 `请回中位`），把杆回中即可
> - **S1 现在是"停机锁存"**：按一次停住、再按一次解除；切出接管档会自动清掉
> - **S4 仍是急停锁存**（最高优先级），解除也要按 S4
> - ★ **模式只有两档**（手动接管 / 屏幕光标），原来的"自动"档已按需求方要求删除
>
> **切菜单 / 切页（两段式，2026-10-16 需求方明确）**：
> - **模式开关打到"屏幕光标"档**后，**油门摇杆向上拨 = 高亮上一项，向下拨 = 高亮下一项**
>   —— 需求原文 §17"使用摇杆上下拨动来切换选项"。
> - **★ 摇杆只移动高亮，必须按遥控的"确认"键才会真正切页**（需求方 2026-10-16 明确）。
>   也就是说：菜单高亮（`menu_sel`）与内容区显示（`page`）是**两个独立状态**，确认键把它们同步。
> - 拨到位后**必须把杆放回中位**才能再拨一次（`MENU_STEP_TH = 400` / `MENU_IDLE_TH = 150`）：
>   杆停在端点不会连续翻页，这是有意的。
> - 手动接管档下摇杆是**开车**，不参与菜单（需求原文 §13：摇杆操作屏幕只在光标档）。
> - **板载 S3 保留为"无遥控时的备用翻页"**；遥控 `select` / `confirm` **不再参与菜单拨动**
>   —— 按 §33 它们属于路径点导航页（切辅助菜单项 / 确认路径点），该页尚未实现。
> - ★ **接管档下按"确认"也切不了页**（需求方 2026-10-16 明确："接管档手柄不做遥控车辆之外的
>   任何交互"）—— `rc_confirm` 与摇杆拨动都限定在光标档。

| `i_imu_miso` | **A16** | J2 SDO/SA0 |

> ⚠ **A15 是 J2.6 = IMU CS**，J1 与 J2 同网络 —— 所以雷达 RX 只能用 **C14**。供电 J2.1 = 5 V。

### ★ 三条接线契约（写死在 `rtl\top\falcons_top.v` 注释里）

1. `gyro_tilt_comp.i_sample_valid` 必须接 `imu_top.o_acc_valid`，**不是** `o_data_valid`
   —— `o_data_valid` 只在 RUN 态产生，标定窗口期内一个样本都收不到，会让倾斜补偿
   **永远不生效且不报错**（`car_fpga` 踩过的坑）。
2. `gyro_tilt_comp.i_calib_start` 接 `imu_top.o_calib_busy`。
3. `yaw_integrate.i_sample_valid` 接 `imu_top.o_data_valid`。

`imu_top` 的 **`SCK_HALF_DIV` 显式写 25**（1 MHz）：源码默认 3（8.33 MHz）实测会导致
8 KB 配置加载失败，表现为 `o_err_code = 2`，极易误判成"模块坏了"。

## 八、上板测试顺序建议（第一次跑按这个顺序走）

> 原则：**每一步都要有一个"能不能继续往下走"的判据**，别一步跳到"摇杆开车"。
> 全程 **车轮悬空**（车架空）、**D24A 驱动板 STBY 跳线帽已拔**，落地试跑放到最后一步。

| 步 | 做什么 | 看什么 / 判据 | 不对时先查 |
| --- | --- | --- | --- |
| **0** | 只烧 **SRAM**（`-Action Sram`），不急着固化 | LED7 心跳（约 0.34 s 翻转）、LED3 遥控信号有效、屏幕出现四页菜单、串口有 CSV 输出 | 没心跳 → 位流没下进去；LED3 不亮 → 接收机没通电/没对码/接错通道；无 CSV → 串口波特率或 TX 引脚（M15） |
| **1** | **核对槽位映射与行程**（实际 5 路 + 1 路闲置）：逐个拨摇杆/开关，看串口 CSV 的 `steer` / `throttle` / `mode` 列 | 摇杆推到两端应到 ±1000 附近；回中位清零；拨杆两档 → `mode` = 0/1；**J6.6（F19 / bit5）无跳变是正常的**（闲置未接，已由掩码排除在判定外）。★ **按钮要另判**：12 列 CSV **没有事件列**，`确认` 的现象是"按一下切页"、`select` 当前**顶层未消费**（导航页未实现，按了屏幕上不会有反应）；`J6.4/F18` 单动**不应**改变 `steer`/`throttle` | 槽位对不上 → 改 `rtl\rc\ht10a_input.v` 的 `CH_*`（本车取值由 `falcons_top.v` 的 `u_rc` 例化给出）；方向反了 → 先确认是不是**极性口径**问题（见下方第 2 步与 `工作记录.md` §35），再动 `STEER_REVERSE` / `THROTTLE_REVERSE`（同样在 `u_rc` 例化处） |
| **2** | **车轮悬空、拨杆打到"手动接管"档**（油门先回中位），看四轮转向与 `tgt` vs `act` | 推油门四轮**同向**、转速随杆位变化；`tgt` 与 `act` **都为正**且符号一致、`err` 接近 0（口径：内部"正 = 物理前进"，见 `工作记录.md` §35）；LED6 亮 = 已使能 | 某个轮反向 → `INV_DIR_VEC` 对应位，或显示侧 `RPM_DISP_INV` 对应位；实测与目标符号相反 → `ENC_INV_DIR_VEC`（**改错会变成正反馈**，改完必须立刻看是否发散）；一给油就报堵转 → 确认已改成 50 窗口；LED6 不亮 → 看状态栏是不是 `请回中位`/`无信号` |
| **3** | **串口 `P/I/D` 在线整定速度环** | 给固定杆位，`tgt` 稳定、`act` 跟上且不振荡；稳态误差 ≤5% | 见 `doc\参数总表与待定清单.md` 第九节第 5 条 |
| **4** | **落地低速试跑 + 保护验证** | 低速直行不跑偏；人为堵住一个轮 → ~200 ms 内停机并锁存（LED2）；**拔掉接收机** → 100 ms 内摇杆归零停车。★ **"关发射机"是另一种故障，必须分别测**：接收机可能保持旧油门，PWM 有效 ≠ 无线在线（failsafe 未实测前不能写"关遥控一定停车"，见 `doc\HT10A接线与验收.md` §4） | 停车时间不对 → 看 `TIMEOUT_US`；堵转不报 → 看 `STALL_*` 阈值 |
| **5** | 功能都正常后再 **固化到 Flash**（`-Action Program`） | 断电 → 拔下载器 → 重新上电 → 现象与 SRAM 一致 | 上电不工作 → 确认烧的是 `impl\pnr\falcons.fs` 且时间晚于最后一次改 RTL |

> ⚠ 第 2 步之前**不要让车落地**；第 4 步之前**不要给大油门**。
> ⚠ 上电后等 **约 3 秒**再动车：IMU 的零偏标定（`CALIB_TIMEOUT_MS = 3000`）要求这段时间静止，
