# AI视觉巡检：使用与架构

状态核对：2026-10-29。RK已部署多路径点巡检、停车后三帧定位、双路录像及发现播报代码；实车自动巡检尚未验收。最近部署、硬件反馈与时序见[验证记录](AI巡检验证记录.md)，录像导出与清理见[录像与报告](AI巡检录像与报告.md)。

## 使用范围

AI模块保留四个独立入口：语义导航、目标识别、聊天机器人、视觉巡检。巡检只在第四项内部管理自己的点位、目标、轨迹和录像，不改原导航页面的点表。

- FPGA的OV5640只供原摄像头页，本地画面已旋转180°；不上传RK。
- AI全部使用RK直连UVC相机。相机、音频和高速接口按设备身份发现，不固定USB插座或video编号。
- 语义导航和聊天不依赖FX2。独立目标识别通过FX2显示RK带框画面，缺少高速线时仍可保留文字识别。
- 原摄像头、雷达、导航、参数整定、手柄及其字形都在FPGA；RK断连后基础功能可独立使用。
- 首版检测四类：胶带、螺丝刀、AD钙奶、营养快线。最低置信度25%，含恰好25%；推理、结果接收和巡检定位统一使用同一阈值。当前模型不含剪刀。

雷达用于道路结构和能测到的障碍；贴地物体坐标来自视觉。当前定位采用固定相机和平地H，不属于双目定位、完整SLAM、全场覆盖巡检或机械拾取。

## 遥控操作

接线以[HT10A表](HT10A接线与验收.md)为准：CH5/SWA下拨确认、上拨返回，CH7/SWC上手动、下光标，CH6/SWB下拨录音、上拨结束，CH8/select上下选择。VRA/VRB已取消。

1. 光标挡选择左侧“AI模块”，SWA确认开启总开关；CH8选择第四项“视觉巡检”，SWA进入。
2. CH8切换摄像头、地图、文字三视图。地图页默认由摇杆移动准心。
3. SWA打开右侧操作面板，默认“添加路径点”。面板打开时摇杆上下选操作，每次选择先回中再拨动，准心不移动。
4. 可执行“添加路径点 / 撤销末点 / 清空路径点 / 开始巡检”。添加、撤销、清空后回到准心操作；雷达障碍格不能添加。
5. 选择“开始巡检”后复核点数，再次SWA确认启动；返回保留点位并继续编辑。空队列不能开始。
6. 面板打开时返回只关闭面板，CH8切页也关闭面板，不执行选中操作。

执行顺序为实际任务起点 → P1 → P2 → … → Pn → 按最新地图返回起点。点间路线由FPGA避障导航规划，虚线仅表示访问顺序。每点收到当前命令的到达且停车回执后才推进；中间点自动继续，最后一点完成后更新视觉障碍层并返航。无路保留当前点，不跳过；返航允许换路，不要求倒序访问点位。

| 操作或状态 | 结果 |
| --- | --- |
| 运行中SWA或返回 | 暂停，保留当前点和完成进度 |
| 暂停后SWA | 更新图层后继续当前未完成点 |
| 暂停后返回 | 取消并结束录像，确认停车或巡检已释放控制权后返回AI功能页；不自动返航 |
| SWC切手动 | FPGA先停车再交手柄；保留AI总开关、任务页和进度 |
| 回光标挡 | 保持暂停，明确确认后从当前位置规划至当前点；不改变返航起点 |
| 未开始、完成或取消后返回 | 返回AI功能选择页；再返回关闭AI总开关，回到主菜单 |
| 完成或取消后SWA确认 | 新建任务，清除旧点位和进度，准心回当前车位 |
| 运行或暂停时修改路线 | 不提供编辑；取消后新建任务 |
| S2定位清零 | 结束旧录像并保存报告，清空点位和进度，回到新任务编辑状态；不自动续跑 |
| 控制断连 | 旧任务失效并保存报告；重连不自动续跑 |
| FPGA复位或重新上电 | 明确复位握手结束旧录像并保存报告；RK清空临时任务、对话及显示缓存，回到空白任务编辑状态；AI总开关保持关闭 |

SWB仍用于录音。进入AI、换功能或手动恢复后需先上拨再下拨；巡检中开始录音会先暂停，继续/开始口令仍需SWA确认。任务内返回与AI总页返回不同：AI总页返回才关闭总开关并解冻左侧菜单。

进入巡检以FPGA的AI总开关和页面为准，不要求先关闭再重开AI，不用SWB有效性、模型加载状态或0.5秒控制包间隔锁住页面。每次确认进入都清除上次返回请求，并以第一份页面输入作为按键计数起点；旧返回提示和旧按键不会带入新页面。

退出不依赖相机、标定、FX2或任务运行许可；停车或控制权已释放即可关闭，不额外比对任务命令号。返回收尾期间不接受新任务或录音，手动接管取消待退出请求。正常确认或CH8切页保留完整前台画面，新视图完整到达后再替换。

启动和继续时检查一次实际所需的相机、地图、标定、图层及高速接口；缺项直接列出名称，不要求重新开启AI。不在每次循环及发送GOTO前重复检查这些条件，也不因控制包间隔或序号跳变使任务失效。FPGA本地手动、急停和停机优先级保持独立。

## 识别后停车、停稳后定位

当前按演示项目要求信任传感器数据，不以传感器年龄、对时精度或动态验收标记阻止巡检；仅假设摄像头延迟不超过0.3秒。巡检巡航速度由RK的`config.json → inspection.cruise_speed_mm_s`设置，默认300mm/s；每条去程、恢复、绕行及返航GOTO均携带该值。FPGA复用避障导航执行器，但巡检时不使用参数整定页的V_CRUISE，不再单独限幅到±120。减速距离和转向PID仍由FPGA参数页控制，减速斜率按RK速度重新迭代计算，输入与运动输出均保留寄存拍。修改RK配置后重启协调服务生效，设置保存在RK上。基础导航仍完全使用FPGA参数，不依赖RK。语义导航的有界前进/后退独立固定为速度码229（理论约300mm/s），不随巡检配置变化。

控制协议的第8个32位字为`cruise_speed_mm_s << 16 | layer_version`：高16位是物理速度mm/s，低16位是视觉图层版本；300不再通过旧8位速度码编码。RK软件与FPGA位流需成对更新。

```text
行驶中连续3个处理帧确认新目标（置信度≥25%、同类框IoU≥0.3）
→ 原有STOP完成回执
→ 固定等待0.3秒
→ 保存当前FPGA地图位姿，开始新的采图轮次
→ 本轮最多处理10张新图，按目标累计3个有效地面H定位样本并求平均
→ 发布目标和完整视觉障碍层
→ 对应版本提交回执
→ 继续当前去程路径点或返航起点
```

相机持续采集，只保留最新待处理帧，因此三次推理之间可以跳过相机中间帧。等待前已经在途的推理结果不属于新轮次，不参与定位；不要求20ms对齐、不做位姿插值或轮速/陀螺仪停稳证明。

胶带、螺丝刀采用检测框中心作为演示接地点；AD钙奶、营养快线采用框底边中心（底部像素为y2−1）。调用链为原图像素 → `undistortPoints(K,D,P=K)` → 去畸变像素H → 右/前厘米 → 前/左米 → 用保存的车辆位姿转换至地图。视频和模型输入并未因此整帧去畸变。

| 参数 | 当前值/来源 |
| --- | --- |
| 相机 | 1280×720 MJPG，focus=260，关闭自动对焦；逐帧V4L2控制读回 |
| 标定 | 已部署14点去畸变H，前向40cm起；40cm处横向±20cm，完整范围按凸包，径向上限2.1m |
| 同类目标关联 | 15cm内最近目标；同轮累计3个有效定位样本，确认前算术平均 |
| 停车前去重 | 同类别且距本次任务已确认目标<30cm；半径由RK配置`inspection.dedup_distance_m`控制 |
| 去重位姿 | RK缓存最近2秒位姿，在推理前按原生取帧`received_at_s−0.3s`选最近样本并随帧冻结；不减识别完成时刻 |
| 演示膨胀 | 物体半径0.05m、位置余量0.03m、车体半径0.20m；标称规划总半径0.28m，多帧位置偏移可增大物体占地 |

类别锚点由`inspection/objects.py`的`GROUND_ANCHORS`维护，并保存到本次巡检报告。地图使用5cm网格，圆形覆盖相交网格，因此栅格边缘会向外取整。膨胀仍使用原有演示常数，不是实测误差保证。完整H和近点验证见[标定记录](七点地面单应性标定_20261028.md)及[投影接口](../host/ai_coordinator/inspection/HOMOGRAPHY.md)。旧的高度20.6cm、前移19.6cm、俯角20°不再用于当前H定位。

`Calibration.locate_stopped()`为现行巡检入口；库中保留的`locate()`、`timebase.py`及`commissioning.py`不是第二条巡检运行流程，其20ms约束和未完成动态标记不作为当前准入条件。控制链失联停车、退出和录像收尾逻辑仍按原实现工作。

## 发现播报与独立识别

目标完成三个有效定位样本后播报一次“发现xx”，按会话/任务/定位纪元/目标编号去重。播放完成后才标记已播；排队、合成或播放失败及暂停取消不算已播。回光标后SWA确认恢复可重新通知未播目标，不会仅因恢复档位自动重播。切页、返程重见不重复，不同位置同类目标分别处理。独立目标识别、普通预览和基础功能不触发巡检发现播报。

四句中文已由既有Kokoro预合成，缓存于RK运行根的`inspection_speech/`，`index.json`记录文案、时长和SHA256。现场直接播放WAV，不重复推理；缓存可在服务停止后清理，需要时重建。`inspection.discovery_speech.names`保留新增类别中文名称接口，模型类别也需相应扩展。

暂停、手动、录音、退出、取消等会清理待播及当前播放，恢复后不补播旧事件。缺扬声器只记错误，不阻塞巡检或录像。`/status`和报告中记录的是播报尝试，不等同现场已听到；本项实物播报仍待测。

独立目标识别与巡检共用RK相机、模型和同帧框渲染，目标识别页只显示画面/框/中文类别，不获得巡检导航权限或自动创建录像。2026-10-27屏幕显示已由用户确认，之后新增的多点面板仍待现场检查。

## 实现与接口

| 部分 | 职责与代码 |
| --- | --- |
| RK任务 | `inspection/mission.py`维护队列、实际起点、阶段与回执；`controller.py`接现有唯一串口、相机/模型worker、图层和录制 |
| RK数据 | `calibration.py`投影，`objects.py`目标目录，`grid.py`生成raw/cost，`render.py`渲染三视图 |
| FPGA导航 | 复用八方向Dijkstra、地图/路线复核、前探、点控制器、四轮PID；不接入被排除的队友全向导航方案 |
| FPGA图层 | 独立双bank视觉raw/cost，停车后完整CRC提交；与雷达地图读取结果合成，不直接改写雷达存储 |
| FPGA显示 | `rtl/ai/`高速接收和DDR双缓冲，内容区816×420（x208～1023、y120～539）；菜单、状态和本地紧急提示由FPGA绘制 |

地图256×256、每格50mm，范围`[-6.4,6.4)`米，地图x前/y左。raw/cost每张8192字节，逻辑双bank共32KiB；`effective_raw = radar_raw OR visual_raw`，cost同理，RK预先计算视觉膨胀。图层切换使旧规划失效，不只改变显示。

控制串口沿用115200/8N1和MOT1保留信封0x60/61/62，事务最多32个uint32，头及负载整体CRC32。类型包括HELLO、CONTROL、图层BEGIN/DATA/COMMIT、心跳、UI_CLOSE和状态/位姿/输入回传。CONTROL含session/task/epoch/command、格坐标、图层版本及物理确认令牌；速度码固定30。同一授权任务可依次下发多个GOTO，手动或人工暂停撤销旧授权。

高速线为RK USB-A Host → FPGA J5高速Type-C，控制串口另留。FX2为04b4:00f1、interface0、EP2 OUT/EP6 IN（Bulk512）；只加载受校验的原厂30MHz运行RAM固件，不写EEPROM。新连接先实际测频与特征诊断；PA0固定低是该固件正常回传的必要板级配置，见[固件说明](../host/ai_coordinator/inspection/firmware/README.md)。

AIF1使用48字节小端头和头/载荷CRC：DISPLAY为816×420 RGB565LE、685440字节；CONTROL仅允许完整图层事务；MAP为8192字节位图；ROUTE为最多64个格点的当前规划前缀；DIAGNOSTIC用于测频回环。HELLO、心跳及运动控制仍走串口，USB显示不能授权运动。无FPGA相机图像上传支路。

帧缓存复用唯一DDR控制器，像素帧边界切换，原摄像头地址区独立。FPGA实现采用同步RAM、异步FIFO、寄存仲裁和分拍CRC；后续RTL改动需重新验证实际时序，不能沿用旧报告签核。

## 日常检查

RK运行根为`/home/orangepi/workspace/falcons_ai_coordinator_20261024_r1`。以其中`active_release.json`和`config.json`查询实际运行代码与标定，不写死历史release或热点IP。

```bash
systemctl --user status falcons-ai-coordinator.service
journalctl --user -u falcons-ai-coordinator.service -n 30 --no-pager
curl -s http://127.0.0.1:18765/status
```

`inspection.mission`给出路径点/进度，`readiness`给出相机几何、相机、FPGA接口、地图和已提交图层；`discovery_speech`、`recording`分别用于播报和录像。最近记录中FX2按用户要求暂不接回、扬声器未枚举；模型加载完成不能替代这些外设的现场验证。


当前视觉使用K541 P02 FP16及CPU连续确认。NMS IoU=0.65；新轨迹连续3个处理帧命中后才向识别显示和巡检输出，已确认轨迹在0.6秒内可恢复关联，当前帧未检出时不输出历史框。相机重新打开会清空关联；单图离线诊断只返回原始框，不积累确认。原始框保留在推理结果raw_detections中。该确认层增加首次视觉停车等待，STOP/急停/手动接管仍走原链路；停车后等待0.3秒及三帧正式定位、地图去重不变。


定位按目标累计有效样本，空检测帧不计入样本数；单个目标超出实测区域时记录原因并跳过，不丢弃同帧正常目标。每轮最多处理10张新图；已满足3个有效样本的目标才进入障碍层。全部不足时暂停，提示用户调整后SWA重试，不自动恢复或假报定位完成。轨迹记录达到512点后仅标记截断，不影响巡检/返航与人工恢复。

存储异常后，SWA先重新检查记录目录和可用空间；检查成功只清除异常，仍需再次SWA确认任务。存储仍不可用时继续显示具体错误，不要求重启协调器。
