保留应用 RTL、Gowin IP、片上字库、整车约束、生产依赖、应用及模块仿真，
以及 RK 四项 AI 功能、自启部署、录像、标定、模型训练和验证工具源码。

提交副本排除 Git 历史、Agent 指令、构建网表和位流、仿真库、缓存、日志、录像、
原始采图、历史联调证据，以及未接入整车的 ToF/旧 FPGA 相机传 RK 模块和独立板卡例程。
`camera_fx2_direct/rtl/acg_async_fifo.v` 被当前整车引用，单独保留；
独立例程中的重复 DDR3 IP 不再复制，整车实际使用的 `rtl/ip/` 完整保留。

只从受 Git 跟踪的项目文件和本次打包脚本、说明中选取文件，因此不会将本地散落的
下载包、私有临时脚本和其他未跟踪文件自动装入提交包。
文件选择与排除理由均由脚本导出，见 `FILE_MANIFEST.json`、`SHA256SUMS`、
`EXCLUDED_TRACKED_FILES.csv` 和 `SOURCE_INFO.json`。

交付文档与源码已去除旧项目仓库链接及学校标识。历史说明中的本机路径统一使用
示例工作目录；这些路径说明已作匿名化处理，不能作为原始日志字节指纹使用。
第三方许可、原作者声明及必要的上游技术来源保留。

归档后的源码导出文档清单已指向现行导航、AI联调和RK启动指南；主题档案及阶段过程不进入源码交付包。路径合并需随本轮变更提交后再导出，避免Git跟踪清单仍指向已迁移的旧文件；导出前先检查工作区是否缺少源码。

## 源码与运行资产的区别

本次交付为源码包，不是 RK 系统镜像。源码中含标定参数、配置示例、原生采集 C 代码、
RKLLM 适配 C++ 代码及 FX2 固件，但不含当前 RK 的模型权重、运行配置、SDK 动态库、
Python 环境和预合成语音缓存。若竞赛还要求模型权重或开箱即用的板端运行包，应另从 RK
导出当前实际资产，不能使用示例配置或 10-24 历史模型清单代替。
本轮没有访问或改动 RK，也没有烧录 FPGA。
