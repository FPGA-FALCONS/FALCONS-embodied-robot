# AI模块页面与遥控交互

核对：2026-10-28。左侧第七项“AI模块”是AI总入口，原数据、相机、雷达、导航和整定仍在FPGA独立运行。四功能操作及当前部署状态分别见[巡检指南](AI视觉巡检.md)、[验证记录](AI巡检验证记录.md)。

## 操作

1. 光标挡选择“AI模块”，CH5/SWA下拨确认开启总开关。
2. CH8/select上下选择语义导航、目标识别、聊天机器人、视觉巡检，SWA确认激活；只移动高亮不会切换功能。
3. CH6/SWB下拨录音、上拨结束。进入/切换/恢复后先上拨再下拨，最长30秒，保持下拨不重复录音。
4. AI总页SWA上拨返回，关闭总开关。视觉巡检任务页使用自己的面板/暂停/取消逻辑，不直接关闭总开关。
5. SWC切手动保留总开关、当前功能和页面，停止当前作业/播报；回光标后明确确认或重新录音，不续跑旧作业。

select对应CH8的`rc_aux_up/down`，CH6的旧`o_btn_select`不参与页面选择；VRA/VRB不接入。完整针号及极性见[接线表](HT10A接线与验收.md)。

## 四个功能及依赖

| 功能 | 行为 | 所需外设 |
| --- | --- | --- |
| 语义导航 | 转写经规则/C1b生成有界MOT1运动；RK直行速度码30 | 控制串口；语音输入需要麦克风，不依赖相机/FX2 |
| 目标识别 | RK独立UVC检测，显示同帧框/中文类别，置信度≥50%；语音可筛选四类目标 | 相机；带框画面需FX2，缺高速线保留文字识别；不产生巡检运动权限 |
| 聊天机器人 | 既有Qwen3.5 0.8B RKLLM生成回复，Kokoro合成人声 | 麦克风/扬声器；不依赖相机/FX2，不进入运动解析 |
| 视觉巡检 | RK管理有序点位、停车后三帧H定位、视觉障碍、返航、录像和发现播报 | 控制串口、独立相机、FX2及地图；运动需SWA确认 |

FPGA摄像头只在原摄像头页显示，不上传RK。AI高速线不是总开关、语义导航或聊天的准入条件。巡检中CH8切相机/地图/文字；地图SWA打开添加/撤销/清空/开始面板，详细步骤只在巡检指南维护。

## 显示

总页四个24px大字标签在各自180×44框内居中；巡检三个视图标签为216×44。选中项蓝底黄字，不用白框。任务文字由RK提供，动态字形使用RK已有中文点阵；AI以外的所有必需字形仍在FPGA。

AI开启时左侧菜单冻结变暗，背景0B1019、未选中文字5A6170、选中文字8A7A2E，原蓝色选中带保持；手动保留AI时继续冻结。AI关闭后菜单恢复正常亮度。高速AI内容区816×420，不覆盖本地菜单、状态栏及紧急提示。

## 控制优先级与恢复

| 场景 | 当前行为 |
| --- | --- |
| SWC切手动 | FPGA本地压制自动输出，先停车/回中再接管；RK取消本次录音、推理、播报，页面和进度保留 |
| 手动回光标 | 维持暂停；巡检确认继续当前未完成点，其他AI功能可确认新作业或新录音 |
| AI总页返回、离开AI、S1、S2清零、急停、遥控失效、RK断连 | 撤销AI任务与运动授权；恢复不自动开启AI或重放旧结果 |
| 巡检页返回 | 编辑面板打开时只关面板；运行时暂停；暂停后取消并退出；未开始或完成后直接退出到AI功能选择页 |
| FPGA复位 | FPGA关闭AI；RK收到复位标记后结束旧记录，清空任务、对话和显示缓存，重新上传所需字形；模型和标定文件保留 |
| 录音开始或切换功能 | 撤销旧作业/播报及其运动，录音结束只处理本次语句 |
| 断连后恢复 | 新会话重建；基础功能继续可用，旧任务不续跑 |

SWC底盘接管完全由FPGA完成：至少200ms制动、三个新编码器窗口四轮增量≤±2、双摇杆回中后交手柄。该原有手动接管判据与RK演示巡检的固定0.3秒等待是两条不同流程。

巡检完成或取消后，SWA确认用于新建任务，上拨返回用于退出。AI功能选择页再次返回关闭总开关。每次明确进入巡检都清除旧返回请求及旧按键计数，不沿用“正在返回”状态。退出只等待停车或控制权释放，不额外核对命令号。

RK直接接受当前FPGA总开关状态；服务重启、重连、短暂控制包间隔不要求用户先关再开AI，SWB有效性和模型加载状态不阻挡页面选择。录音仍需先上拨再下拨，旧任务不自动恢复。任务缺少相机、地图或FX2时直接列出缺项。切换/确认时保留上一张完整画面，新视图完成后在帧边界替换。

语义MOT1运动、原导航和巡检在FPGA仲裁；聊天与显示没有运动权限。MOT1串口写入不是物理完成回执，巡检到点依赖自身真实状态回执。受控归还原导航需原页面明确开始/继续，不暴露断连前的旧目标。

模型自启与就绪音见[自启记录](RK模型开机加载与手动暂停_20261025.md)，固定速度码见[速度记录](RK前进后退固定速度码_20261025.md)。现场验收结果只在验证记录维护，不在此复制旧release、旧测试总数或已经弃用的交互。
