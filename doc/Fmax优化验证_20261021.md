# Fmax 前四项优化验证（2026-10-21）

## 范围与版本

执行 [Fmax 优化方案](Fmax优化方案_20261021.md) 的 P1-1～P1-4，未启用 P2 资源复制，未改变时钟约束、公开接口、地图 / 导航策略、摄像头或 DDR 数据通路。

开始前按用户要求拉取。远端至 `6fc8bcd`，含 IMU 标定失败显示、系统复位重新标定及模块硬件故障排查记录。将本地未推送的两次导航提交重放到远端最新版本，冲突处合并文档，双方功能保留在同一份代码中；本轮修改基于整合后的 `f93716f`。

对比报告仍为 19:31 的 `873908b`：此报告早于上述整合，故下文差值包含队友的顶层 IMU 修改，不能作为四项优化的严格单变量收益。没有为补一轮合并基线而额外执行长布线。旧报告、综合网表及约束指纹保存在 `logs/fmax_p1/baseline/`。

## 已实施的结构

| 项目 | 实现 | 内部周期变化 |
| --- | --- | --- |
| P1-1 | `nav_ctrl` 使用 `dot_r/cross_r`；锁存阈值后并行比较四字节，再合并结果 | 沿用 `M_A1 → M_A2 → M_V1 → M_V2`，无新增状态或测量周期 |
| P1-2 | IMU 换算后锁存同份六轴数据，下一拍锁存标定判定，再提交计数、均值、零偏及输出 | 从采到 `op_done` 到结果提交新增 2 周期，50 MHz 为 40 ns；采样与超时时间尺度不变 |
| P1-3 | 小字选择结果先寄存，只保存实际使用字段，再计算 ROM / RAM 地址 | 文字内部从 2 拍变 3 拍，预读从 x+2 改为 x+3 |
| P1-4 | 大 / 小字的预读列号分别随 2 / 3 拍读取流水传递 | 不增加外部 RGB 延迟，不修改 HDMI 同步、摄像头取数或双缓冲交换时序 |

像素流水以扫描器在时钟沿后推进坐标为约定：

| 阶段 | 大字 | 小字 |
| --- | --- | --- |
| 请求像素 P | 当前 x+2；组合选段与字符地址 | 当前 x+3；组合选段 |
| 第 1 沿 | 读取字符，锁存列号 | 锁存选中段、字组与列号 |
| 第 2 沿 | 读取字模行，列号到达位选择端 | 读取字符，传递列号 |
| 第 3 沿 | — | 读取字模行，列号到达位选择端 |
| 输出 | 扫描到 P 时，字模位与原有背景、地图、路线组合 | 同左 |

没有复制一套旧接口或旧渲染通路；公开端口及数据单位不变。

## 综合与布局布线

初次综合用时 263.7 s，确认 IMU 换算寄存进入三个陀螺 DSP 的 `OREG_CLK="CLK0"`，标定判定、投影及显示选段 / 列号寄存均保留。随后调用现有 `build_pnr.tcl` 时，实际日志显示它在新 Tcl 会话中仍触发了综合，并没有按注释直接跳过。

进一步核对该次综合报告，`cut_ok_r` 的剩余比较被映射为 26 级链，估算 slack −2.186 ns。此时布局尚未完成，已停止该任务自己的 `gw_sh build_pnr.tcl` 进程，没有生成可比较的新 Fmax。按方案中的后续处理，利用原有阶段锁存阈值、并行比较四字节并合并，不增加控制周期；补 264 组对照通过后重新运行完整回归和单入口 `build.tcl`。这是一次早期中止和一次最终完整构建，没有开展选项组合试验。

最终全量构建退出码 0，用时 1211.8 s（20 min 11 s）；其中 PnR 报告记载 15 min 21 s，位流完成于 21:24:22、时序报告完成于 21:24:27。此耗时不包含前述已中止的尝试。实际 PnR 命令与 19:31 基线逐字一致，SDC / CST 指纹也不变。

| 系统 i_clk_50m | 50 MHz | 44.154 MHz | **50.018 MHz** | +5.864 MHz | **+0.007 ns** |

系统 / 像素同域 setup 违例分别由 296 / 38 降至 0 / 0，TNS 均为 0；两域 hold 仍为 0。两个目标时钟满足当前约束，**但余量很薄，尚未达到方案中期望的 +0.5 ns 余量**。以上为布线后 STA 结果，不是实车超频实测。

全设计 setup 违例端点由 392 降至 58，hold 仍为 18；最差列出项为 DDR 的 clk_cam200 → clk_ddrf 相关时钟路径，setup 最差 −4.431 ns。没有修改该 IP 或其约束，不能宣布整工程时序收敛，也不能把这些路径直接视为误报。

新的同域最差路径已转为：

1. 系统：非避障准心毫米坐标 → 厘米显示寄存器，+0.007 ns；页面选择 → 同类换算寄存器 +0.029 ns。
2. 系统：遥控量 → 非避障准心更新，+0.039 ns。
3. 像素：水平扫描 → 大字静态文案 ROM 地址，+0.044 ns。

后续若继续争取余量，优先评估显示坐标的选择 / 换算分级，以及大字选段到字符 ROM 的分级；本轮不扩大到这些路径，不开启资源复制试验。
