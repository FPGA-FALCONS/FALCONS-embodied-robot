## 装车接口与联调清单

供持板队友使用，配合[统一下载入口](../../全栈上板与队友下载_20261024.md)。源码/仿真/当前SDC通过不等于实车已通过；记录实物结果后再解除相应功能HOLD。

| 环节 | 队友准备 | 验收记录 |
| --- | --- | --- |
| 供电与固定 | 两板各按原方案供电，固定麦克风/相机/线束，确认USB供电关系 | 上电电压、USB稳定、无复位 |
| 遥控/急停 | 保留原HT10A通道、硬件急停与手动接管 | 架空轮时能独立停机，失联不自行恢复 |
| FPGA下载 | JTAG下载口，当前Release位流，SRAM Program | 设备型号、位流SHA、下载日志 |
| RK–FPGA串口 | 按已有整车UART接线与电平方案，TX/RX交叉、共地，115200/8N1 | 两端设备路径/串口唯一所有者；不把USB高速图像口当作UART |
| 语义运动 | 先dry-run，再由操作员显式选串口，测试前后退/停及左右90度/顺逆360度 | 实际方向、转角、漂移、停车；零位/IMU校准状态 |
| 异常停车 | 中断心跳、断串口、切手动/急停、转向中IMU停更 | 控制目标归零时间与实际停稳；原导航非零也不恢复 |
| 中文语音 | 同一次capture job说新口令，分别静音和电机运转 | 原始转写、规则结果、是否误执行/漏停；不以文本测试替代 |
| 摄像头 | UVC到货后实际probe/取帧，或独立FX2周末实验 | 模式、完整FPS、CRC/断流、原图检出和目标距离 |
| 播报与录音 | USB音箱到货，固定女声缓存，短句半双工 | 播放时录音互斥与恢复、回声是否误触发 |

本版语音获得控制权后会保持停车，原UI导航不会自动恢复。需要现场整车复位清除语音所有权后再启动原UI导航；手动遥控可独立接管。语音开启巡航和精确米数尚未连接真实路线/距离闭环，不把它们列为装车已完成功能。

协调器仍默认HOLD/shadow，生产FPGA还没有完整FAM1任务协议；不要伪造hello或完成回执让“找物成功”看起来通过。先完成独立MOT1架空轮验收，再对齐巡航路线、停车距离、执行回执和视觉时间戳，最后做完整找物场景。

每次联调保留：Git提交号、位流SHA、板端release、配置、操作员、场景、实际结果及原始日志。一次只变更一个环节，停止请求、物理停稳和任务完成分开记录。
