- 合集中仅调整标题层级和相对链接。旧命令、参数及否定结论保留其日期；命令中的历史路径不一定仍是当前路径，现行操作优先读模块指南。

- 两个原始证据README仍引用旧自启/UVC报告，故仅这两处保留旧路径跳转页。其他项目内链接已指向合并后的具体章节。
