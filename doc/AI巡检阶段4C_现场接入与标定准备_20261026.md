# 视觉巡检阶段4C：现场接入与标定准备

本阶段继续在 `codex/ai-visual-inspection` 完成非实测标定部分，不合并队友全向导航，不推送。原语义导航、独立目标识别、聊天机器人三个入口保留，视觉巡检为第四项。FPGA复用现有导航器；RK不直接生成巡检电机PWM或定时行驶序列。

## 任务、显示和故障处理

- CH8在摄像头/地图/文字三视图循环。地图编辑时摇杆移动准心，一次SWA确认目标，第二次确认才尝试开始；待开始后摇杆不会暗改目标。其他视图的确认只提示切地图。
- 运行中确认或返回均暂停；暂停确认需重新校验全部条件，并在停稳、最新视觉层提交回执后继续。暂停返回会取消任务，匹配停稳回执后返回AI功能页。完成确认不重跑，返回新建时准心回当前实际位置。
- SWC手动由FPGA本地最高优先撤销自动输出，保留AI总开关和任务页，取消录音/播报及旧显示/上传工作。回光标档不自动续跑，录音需要新的SWB上拨再下拨。
- 返航目标为开始行驶时的实际起点，使用最新雷达与视觉合成地图，可换路；无路停稳等待原导航重规划。去程、返程和手动绕行轨迹都保存，手动移动不改变起点。
- 串口遥测中断或重启重建新会话，旧定位任务失效并保存报告；FPGA数值纪元重复不代表坐标连续。定位清零同样先保存旧坐标报告再丢弃旧位姿，不允许旧排队GOTO进入新坐标系。
- USB/相机断开会撤销相应就绪条件、暂停运行。相机按身份重新发现，恢复设备不会自动恢复任务。其他三个AI功能仍按各自依赖运行，不强制要求高速线。

高速新增ROUTE类型5：2字节点数加0～64个二维字节格点，零点数明确清除旧路线；序列携带路线及地图版本。它只是当前FPGA路径前缀的显示/调试数据，不是RK下发的另一套规划器。导出双缓冲、串行CRC、握手和发送与导航主通路分离，不阻塞规划。RK显示车辆朝向、实际去返程、当前路线和已确认目标红点；未标定检测仅画框，不伪造坐标。

## 可换接口与现有模型

相机使用原UVC设备VID/PID/序列号和模式匹配；没有固定video编号或USB插座。音频新增独立角色选择：麦克风 `4c4a:4c55`、扬声器 `0d8c:0012`，来自本车既有设备清单。每次录音/播放重新解析ALSA卡及方向，缺失或多台歧义时明确失败，不回退到HDMI。仍兼容旧设备字符串配置。

部署包只包含源码和已有FX2运行RAM固件，SHA256逐文件校验；用RK已有cc编译原生UVC辅助程序，运行回归后才切换服务。原ASR、语义模型、Qwen3.5 0.8B、Kokoro及四类检测模型路径保留，不下载替换模型、不升级包。失败按已有事务安装器回滚；历史release与配置备份保留。

现场识别到的独立相机为 `0bda:5856 / 200901010001`，控制串口CH340，高速接口为FX2 `04b4:00f1`、480Mbps、EP2 OUT/EP6 IN。FX2仅加载运行RAM，PA0保持低；诊断新开完整一秒测量窗口，确认约30.006MHz内部IFCLK后才启用业务。信号速率不等于有效显示帧率。音频外设本阶段暂未接入，不能据启动模型成功声称播报验收。

## 报告与复现

RK运行目录内 `inspection_reports/` 保存JSON报告，`inspection_evidence/` 保存独立不可覆盖的JPEG关键帧、投影和采样位姿/驱动时间、标定版本、raw/cost层及版本/CRC。每份二进制证据记录SHA256。证据异步队列最多4项、总计128MiB/2048份，失败会暂停任务；轨迹各最多512点，容量不足同样暂停。完整报告区分真实FPGA停稳到点完成和取消/故障，不能由显示或本机计时推断到达。

## 后续实测输入与离线工具

`host/ai_coordinator/inspection/commissioning.py` 提供离线候选计算，所有输出的实测/通过标记保持false，不修改运行配置，不授权运动。采用RK已有OpenCV的[标定与PnP接口](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)，没有要求升级版本。

```bash
PYTHONPATH=host python3 -m ai_coordinator.inspection.commissioning --out intrinsics.candidate.json intrinsics --images checkerboards --columns 9 --rows 6 --square-m 0.02
PYTHONPATH=host python3 -m ai_coordinator.inspection.commissioning --out extrinsics.candidate.json extrinsics --input measured-extrinsics.json
PYTHONPATH=host python3 -m ai_coordinator.inspection.commissioning --out ground.errors.json ground --input independent-ground-checks.json
PYTHONPATH=host python3 -m ai_coordinator.inspection.commissioning --out timing.candidate.json timing --input exposure-observations.json
```

上例棋盘格尺寸是参数示例，必须换成实际实测值。内参至少12张不同视角图片；外参输入 `K/distortion/base_xyz_m/pixels_uv`，至少6组非共线实测点；地面独立验证输入 `profile/samples`，每点含 `uv/xy_base_m/max_range_m`；时间输入至少20组 `driver_timestamp_s/reference_exposure_s`。拟合误差不自动成为可用范围或保守误差上界，需独立验证。

仍需现场完成：

1. 最终安装/对焦/分辨率下的相机内外参、平地范围及独立误差验证；标称6mm/约60°不能替代标定。
2. 四类胶带、螺丝刀、AD钙奶、营养快线的地面锚点、最大占地与保守误差；新增类别接口保留，当前模型不包含剪刀。
3. 指定相机身份/格式/尺寸/fps/时间戳来源下的曝光偏置及误差上界，结合设备对时/位姿插值验证20ms总预算。
4. 车体扫掠半径、速度码30实际速度、制动距离/延迟、视觉最远可靠检测距离、短道路里程计漂移和容差。
5. 标定通过后的真实短路绕障、换路返航、运行中接管和外设断连验收。此前单位/应用仿真不是这项整车现场验收。
