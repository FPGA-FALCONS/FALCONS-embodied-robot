## 21:07–21:14 录音提示音产品化

用户要求在**产品代码**里做录音开始/结束提示音（此前的临时脚本方案只用于现场调试）。新增 `host/ai_coordinator/recording_cue.py`，由 `runtime.py` 在录音窗口两端调用。

- 音色与临时脚本一致：开始 = 880 Hz 0.10 s + 静默 0.05 s + 1175 Hz 0.14 s（合计 0.29 s，升调）；结束 = 660 Hz 0.16 s + 静默 0.05 s + 440 Hz 0.26 s（合计 0.47 s，降调）。44.1 kHz / PCM16 / 单声道，8 ms 淡入淡出，增益 0.35，首次启动时生成到 `<root>/cues/{start,stop}.wav`。
- 时序：`announcements.begin_capture()` → `await cue.play('start')` → ASR 录音 → `announcements.end_capture()` → `await cue.play('stop')`。**开始音播完才调 ASR**，因此不会被录进 3 秒窗口；播放失败只写 `recording_cue_failed` 审计并返回 false，**不会让采集失败**。
- 配置（板端 `config.json`）：`microphone.cue = {"enabled": true, "device": "plughw:CARD=Device,DEV=0"}`。默认 `enabled` 非 true 即完全禁用；与现有 `announcements`（`mode=log`、`device=null`）互不影响。
- 部署：先备份到 `/home/orangepi/workspace/backup_20261024_recording_cue/`（`runtime.py`、`tests/test_runtime.py`、`config.json`），再把 `runtime.py`、`recording_cue.py`、`tests/test_runtime.py`、`tests/test_recording_cue.py` 拷入 active release `fullstack_20261024_181624_c7ae91`。`config.json` 由 python 读改写，**缩进 2 空格变 1 空格（内容等价，仅新增 cue 段）**。重启后 `recording_cue.enabled=true`、`plays=0`。
