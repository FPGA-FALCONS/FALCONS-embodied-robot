## 二、推导量（可直接用于 RTL 定点换算）

| 量 | 值 | 公式 / 说明 |
| --- | --- | --- |
| 轮周长 C | **125.0354 mm** | `2πR` |
| 计数 / 车轮转 N | **61440** | `512 × 4 × 30` |
| 每计数里程 | **2.03508 µm**（0.00203508 mm） | `C / N` |
| 1 rpm 对应测速增量 | **10.24 计数 / 10 ms** | `N / 60 / 100` |
| 1 rpm 对应轮面线速度 | **2.0839 mm/s** | `C / 60` |
| 中心速度 300 rpm | **625.2 mm/s ≈ 0.625 m/s** | 默认上限（见第四节） |
| 差速系数（每侧） | **0.66415 rpm / (deg/s)** | `(π/180) · L/2 / C · 60` |
| 角速度反解 | **0.75284 (deg/s) / rpm** | `1 / 1.32831`，1.32831 = 左右轮速差系数 |
| 原地旋转 90 deg/s | 单轮 **59.8 rpm**（左负右正） | 轮面 124.6 mm/s |
| 1 m 直线 | **491381 计数** | `1000 / (C/N)` |
| 原地旋转 360° | 单轮 **244834 计数**（约 πL） | `π·L / (C/N)` |

> **给 RTL 的定点提示**：`rpm = delta / 10.24` 建议实现为 `rpm = (delta × 100) >> 10`（100/1024 = 0.097656 ≈ 1/10.24 = 0.0976563，误差 < 1e-5）；
> `delta = rpm × 10.24` 用 `(rpm × 41) >> 2`（41/4 = 10.25，误差 0.1%）或 `(rpm × 655) >> 6`（10.2344）。

## 三、编码器线数判定（实测数据反推）

已知实测：**手转车轮一圈 ≈ 61657 计数**（4 倍频后，来自 `class\car_fpga` 标定记录）。

| 假设 | 理论计数/车轮转 | 与实测偏差 |
| --- | --- | --- |
| 500 PPR | `500 × 4 × 30 = 60000` | **2.76%** |
| **512 PPR** | `512 × 4 × 30 = 61440` | **0.35%** ✅ |

→ **判定为 512 线**。实测偏高 0.35% 属手动转动误差（手转一圈的起止点判断、轻微回弹）。

⚠ **这条影响已有标定关系**：`car_fpga` 里 "rpm = delta / 10" 的速度换算隐含 `60000 计数/转`（500 线）假设；
按 512 线应为 `rpm = delta / 10.24`，**系统偏差 2.4%**。速度环整定与目标速度换算必须统一口径，
否则"设定 300 rpm 实际 293 rpm"。本工程统一采用 **10.24**。

> 复验建议（模块库 README 也给过同样判据）：按 S2 清零后**手转 10 圈**，看累计计数 ≈ **614400**（512 线）还是 **600000**（500 线）。
