## 遥控与安全入口

[HT10A表](HT10A接线与验收.md)维护全部接线及开关参数。整车J6六路有效，CH4转向、CH2油门、CH5确认/返回、CH7手动/光标、CH6录音、CH8/select。顶层STEER_REVERSE=1、THROTTLE_REVERSE=0；有效掩码111111。

SWC手动接管原有默认：至少200ms制动、3个新编码器窗口四轮增量均≤±2计数、双摇杆回中±100后交手柄。切回光标不自动恢复任务。PWM超时100ms只表示信号刷新检测，不是已实测的停车距离或射频在线证明。

ToF驱动/独立例程已存在，整车tof_estop=0，尚无生效的ToF急停阈值。待接入事项见[ToF待办](../TODO_RC_CAR.md)。

## 基础导航与地图

地图256×256、50mm/格、12.8×12.8m，范围[-6400,6400)mm。导航为八方向Dijkstra，直步代价2、斜步3；规划与路径复核都使用当前有效地图。

## 显示与存储

七项菜单，默认数据页。FPGA字模252槽：16×16小字ROM深4032，24×24大字与16×24数字ROM深6048；共用字符索引。改文案只改`tools/font_chars.txt`并用生成器重新生成。

动态数值14字段、每字段5字符，顶层字符RAM128字节/7位地址。字段0航向，1～4轮速，5角速度，6中心速度，7/8航位，9/10导航准心；整定页复用0～13显示全部参数。基本字库不依赖RK。

## RK巡检演示常数

相机1280×720 MJPG、focus260、自动对焦关闭；当前去畸变H与前向40cm起凸包见[H接口](../host/ai_coordinator/inspection/HOMOGRAPHY.md)。K/D/H及独立点的数值只维护在profile和原始标定JSON，不在此复制。

| 常数 | 值 |
| --- | --- |
| 巡检巡航速度 | RK配置`inspection.cruise_speed_mm_s=300`（mm/s）；不受FPGA V_CRUISE及旧±120限幅影响，FPGA按该值重算减速斜率 |
| 语义前进/后退速度码 | 30；不是30cm/s，不用于巡检巡航 |
| 相机延迟假设/停车后等待 | ≤0.3s / 0.3s |
| 定位帧数/识别阈值 | 3帧 / ≥50% |
| 已确认目标去重/三帧位置关联 | <0.30m / ≤0.15m |
| 胶带/螺丝刀接地点 | 检测框中心 |
| AD钙奶/营养快线接地点 | 框底边中心（y2−1） |
| 物体半径/位置余量/车体半径 | 0.05/0.03/0.20m；标称规划总半径0.28m，按原有多帧占地与栅格规则生成 |

RK位姿缓存保留最近2秒，推理前按原生取帧时刻减0.3秒选最近样本；缓存仅服务去重，不改变停车后三帧的正式位姿。

这些是演示假设与代码常数，不是实测误差保证。巡检信任其他传感器数据，不使用20ms动态时序或传感器年龄门槛；仍按已配置的相机身份、模式、锁焦与H有效区域进行几何投影。
