# RK部署与运行检查

核对：2026-11-09。本文合并启动检查与语义运动策略说明。现行模型见[模型资产](../host/MODELS.md)，设备和运行状态需连接板端核实，不从历史IP或发布目录名推断。

## 连接与登录

RK与电脑使用可互通网络，按实际地址更新SSH别名`falcons-rk3588`；热点地址会变化。保留CH340控制串口，RK相机直接插RK，FX2线为RK USB-A Host至FPGA J5高速Type-C。下载线单独连接FPGA JTAG。

语义导航/聊天不依赖FX2和相机；巡检和RK带框画面需要相应设备。USB位置可更换，系统按相机/音频/高速设备身份选择，不固定video0或默认HDMI声卡。

## 检查现有服务

```bash
systemctl --user status falcons-ai-coordinator.service
journalctl --user -u falcons-ai-coordinator.service -n 30 --no-pager
curl -s http://127.0.0.1:18765/status
```

`startup.ready`表示所需模型加载完成；就绪提示音还需要扬声器。`inspection.usb`表示高速诊断状态，`inspection.readiness`分别表示静态几何、相机、FPGA接口、地图和图层。ready不等于已开启AI总开关或开始运动。

运行根为`/home/orangepi/workspace/falcons_ai_coordinator_20261024_r1`；`active_release.json`给出实际代码目录，`config.json`给出模型、设备和H。生产相机为v4l2_native、1280×720 MJPG、focus260、自动对焦关闭；独立探测见[UVC工具](../host/usb_camera_v4l2/README.md)。

## 直行与距离指令

所有应用前进/后退指令统一使用MOT1速度码229，理论目标299.76mm/s；由RK的`motion_intents.DRIVE_SPEED_CODE`独立固定，不读取巡检速度配置。普通、定时及通过距离策略的指令均执行此策略，文字、ASR、AI页面、独立`semantic_nav/send_motion.py`和正式发送后端一致。

换算：229×4=916计数/10ms，轮径64mm、每轮61440计数/转，线速度为916×100÷61440×π×64≈299.76mm/s。这是闭环设定值，实际地面速度尚需实测。

`voice_motion.settings.drive_speed`报告速度码229；`voice_motion.speed`仅配置转向/旋转。普通定时、STOP和心跳机制保持原样。距离指令支持0.05–2m，直接按0.3m/s估算，超过单帧5s由RK分段，不要求实测标定开关；不代表实际到达已验证。


各轮部署、用户反馈和误差边界见[验证记录](AI巡检验证记录.md)，不在本文复制测试总数或当时串口状态。
