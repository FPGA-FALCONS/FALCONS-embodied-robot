# 相机与 AI 上板启动流程（RK3588 / 2026-10-24）

适用板卡：Orange Pi 5 / RK3588S，Ubuntu 22.04，用户 `orangepi`。
默认安全状态：协调器 `HOLD/shadow`，`model_loads_enabled=false`，巡航关闭，播报 log。
**禁止**：`apt upgrade`、`apt-get upgrade`、`pip install --upgrade/-U` 或任何等价升级；不要替换系统 Python、NPU/RKNN/RKLLM 驱动；不要动无关文件。

---

## 0. 两条相机路线

| 路线 | 用途 | 状态 |
|---|---|---|
| **USB UVC 直连** | AI 主链路，推荐 | 摄像头已购买，到货后按第 3 节验证 |
| FPGA → FX2 → RK3588 | 可选演示/规则要求时 | 640×375 FIMG v2 实验包；FX2 时序未闭合，**只 SRAM，不写 Flash** |

两条路线共用 RK3588 上的协调器、YOLO、语音和任务链；先不要同时开重负载。

## 3. USB 摄像头（到货后主链路）

- 只读探测，不安装 `v4l-utils`/OpenCV；板端已有环境不动。

## 4. FPGA 直传（可选，实验）

### 4.1 电脑侧烧录

- 文件：`falcons_direct_experimental_SRAM_only.fs`（周末包）。
- Gowin Programmer 选 **SRAM Program**；**不要 Flash Program**。
- 已知：FX2 IFCLK Fmax 40.804 MHz < 48 MHz（5 ns 暂定 I/O 预算），可能偶发坏帧；这是调试项，不是量产签收。

### 4.2 板端收帧

```bash
cd /home/orangepi/workspace/falcons_camera_tools_20261024/host_fx2_v2
python3 fx2_camera/probe.py
cp usb.example.json usb.json
# 按 probe 的真实 VID/PID/interface/endpoint 填写 usb.json，不要猜
python3 -m fx2_camera.receive --config usb.json \
  --out /home/orangepi/workspace/falcons_camera_tools_20261024/sessions/fx2_first \
  --frames 20 --seconds 20
```

- 期望 640×375、FIMG v2、CRC 通过。
- 记录 CRC 失败数、实际 FPS、USB 是否掉线。
- 不加载 FX2 固件、不写 EEPROM、不 reset FX2。

## 5. 协调器启动/停止

```bash
export XDG_RUNTIME_DIR=/run/user/1000
export DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1000/bus

systemctl --user start falcons-ai-coordinator.service
systemctl --user status falcons-ai-coordinator.service --no-pager
curl -s http://127.0.0.1:18765/status | python3 -m json.tool
```

停止：

```bash
systemctl --user stop falcons-ai-coordinator.service
```

- API：`127.0.0.1:18765`；私有 LLM 端口：`18081`。
- 默认 shadow，不发送车辆动作；不要在没有确认时切 live。
- 开模型前先备份 `config.json`，只改 `model_loads_enabled`；不要改 mic/ASR 超时以外的无关字段。
- 板子有不明重启史；模型长测仍需 HOLD，先做相机/YOLO 轻量长跑。

## 6. 语音/麦克风（需要时）

```bash
cd /home/orangepi/workspace/falcons_ai_coordinator_20261024_r1
# 解除 PulseAudio 对 USB MIC 的静音（只改音量/静音，不装包）
for s in $(pactl list short sources | awk '/usb-Jieli|USB_MIC|MIC/ {print $2}'); do
  pactl set-source-mute "$s" 0
  pactl set-source-volume "$s" 100%
done
```

- 设备：`plughw:CARD=MIC,DEV=0`，16 kHz 单声道。
- 播报与录音互斥沿用 `announcements.py` 的 `microphone_blocked`/`begin_capture`/`end_capture`；音箱到货后再做实物回声测试。

## 7. 日志与故障排查

```bash
journalctl --user -u falcons-ai-coordinator.service -n 100 --no-pager
ls -lt /home/orangepi/workspace/falcons_ai_coordinator_20261024_r1/logs 2>/dev/null | head
dmesg | tail -50
lsusb -t
```

- 无 `/dev/video*`：换 USB 口/线，`dmesg | tail` 看枚举。
- USB 相机只有 5–10 fps：USB2 + YUYV，改 MJPG 或换 USB3 口。
- FPGA 无帧：先查 FX2 固件/FLAGC/EP6，不要改固件或升级。
- 板子重启：记录 `uptime -s`、`boot_id`、`dmesg`，停止重负载并通知双方。
