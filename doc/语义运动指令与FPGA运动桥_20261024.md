# 语义运动指令与 FPGA 运动桥（无摄像头）

日期：2026-10-24。范围：中文固定运动短语 → RK3588 → MOT1 串口 → FPGA → 电机。
**不依赖摄像头**；摄像头只用于“找螺丝刀/找物”，语义运动不需要它。

---

## 1. 已实现的命令

| 说法示例 | 解析结果 | 执行 |
|---|---|---|
| 前进 / 后退 | `{"cmd":"forward/backward","duration_s":0.8}` | 低速定时 |
| 前进2秒 / 后退1米 | 带 duration/distance；米按 0.2 m/s 估算 | 低速定时（近似） |
| 左转 / 右转 / 左转90度 / 向左转九十度 | `{"cmd":"turn","direction":"left/right","angle_deg":90}` | IMU 偏航闭环 |
| 原地顺时针转一圈 / 逆时针转一圈 | `{"cmd":"spin","angle_deg":±360}` | 偏航闭环 |
| 顺时针转半圈 / 转180度 | 带角度 | 偏航闭环 |
| 开启巡航 / 关闭巡航 | `{"cmd":"patrol_start/patrol_stop"}` | 目前只发脉冲；真实航点仍由导航层负责 |
| 停 / 停下 / 停止 / 别动 / 急停 | `{"cmd":"stop"}` | 立即停止 |
| 找螺丝刀 | `None` | 交给 Qwen/视觉任务链，不属于运动原语 |

限制：距离 0.05–2 m、角度 5–360°、时长 0.1–5 s；超限拒绝。规则层先匹配，未命中返回 `None`，不抢 Qwen 的语义任务。

## 2. 主机侧

目录：`host/semantic_nav/`

- `voice_nav.py`：中文规则解析、中文数字（九十/一百八十/三百六十/半）、默认值、限幅。
- `mot1.py`：MOT1 12 字节帧，`MOT1+seq+cmd+value(int16 BE)+speed+flags+CRC16`；编解码/重同步。
- `send_motion.py`：解析并发送；`--dry-run` 可看 hex；Linux 下要求显式 `/dev/serial/by-id/...`，不改 DTR、不复位、不装包。
- `test_voice_nav.py`：8 项测试，覆盖前进/后退/转向/自旋/数字/巡航/停止/非运动/超限/CRC/重同步。

```bash
python -m unittest -v test_voice_nav.py
python send_motion.py --dry-run "原地顺时针转一圈"
```

## 3. FPGA 侧

模块：`vendor/verilog-reusable-modules/modules/voice_motion_bridge/`

- 解析 MOT1；CRC 错/未知命令不启动运动。
- 前进/后退：定时，中心速度 = speed×4，限幅 `MAX_CENTER=1024`。
- 左/右转、顺/逆时针：用 `i_yaw_deg`（整数度，±180 回绕）累计角度闭环；超时 8 s。
- 看门狗 500 ms：收不到任何 MOT1（含心跳）就停车。
- `i_enable/i_estop/i_manual` 电平优先；手动、急停、ToF、规划急停、遥控失联都能压住语音。
- 输出 `o_auto_valid/o_auto_center/o_auto_diff` 到 `chassis_ctrl`；巡逻 start/stop 只产生脉冲。

验证：

- `sim/tb_voice_motion_bridge.sv`：前进、左转90°、顺时针360°、停止、坏 CRC、看门狗、手动接管、巡逻脉冲，**PASS**。
- Verilator `-Wall`：干净。
- Gowin 独立综合：**638 LUT / 341 regs / 0 BSRAM，无警告**。
- 整车候选综合：`voice_motion_candidate_20261024_r1`，语音桥 **507 LUT / 284 regs**；整车 283/340 BSRAM、30,875 LUT、18,047 regs。PnR 进行中。

## 4. 候选顶层接线

- 复用现有 `uart_byte_rx` 的 `rx_data/rx_valid`；PID ASCII 解析器与 MOT1 桥都只读。
- `voice_selected = voice_auto_valid && !planner_emergency_stop`；语音活动时优先于导航/避障 auto，其余时间回落导航。
- `chassis_ctrl.i_enable = manual_drive ? run_en : (auto_selected_valid || voice_selected)`。
- `i_estop = estop_latch | tof_estop | (!manual_drive && planner_emergency_stop)`。
- 遥控手动档 `manual_drive=1` 时语音自动失效；`rc_signal_ok=0` 时也失效。

**测试注意**：语音命令结束后会回落到导航 auto（如果导航当时 valid）。周末架空轮测试时请关闭导航/巡航，确保 `auto_selected_valid=0`，或让车处于不触发导航的页面；否则语音完成后导航可能接管。
